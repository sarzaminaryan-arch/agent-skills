# کنترل کیفیت تصویر پیش از تحویل

تصویر تولیدشده را **قبل از نشان دادن به کاربر** از این دروازه‌ها رد کن. هر «رد» یعنی تولید دوباره، نه توجیه.

---

## 1) دروازه‌ی ادعا

```
[ ] ادعای مقاله در تصویر دیده می‌شود، نه فقط موضوع کلی
[ ] اگر تصویر را روی مقاله‌ی دیگری بگذارم، بی‌معنا می‌شود
[ ] کسی که مقاله را نخوانده، از تصویر یک ایده می‌گیرد نه یک برچسب
```

**تست:** تصویر را به کسی نشان بده و بپرس «این درباره‌ی چیست؟» اگر گفت «چیزهای کامپیوتری» یا «کسب‌وکار»، رد است.

---

## 2) دروازه‌ی صحت بصری

```
[ ] دست‌ها: تعداد انگشت درست، مفصل‌ها منطقی (یا اصلاً دستی در کادر نیست)
[ ] چهره‌ها: چشم‌ها قرینه، دندان‌ها طبیعی (یا چهره‌ای در کادر نیست)
[ ] متن: هیچ حروف من‌درآوردی در تصویر نیست
[ ] منطق اشیا: سایه‌ها یک جهت دارند، بازتاب‌ها درست‌اند
[ ] پرسپکتیو: خطوط به یک نقطه‌ی گریز می‌روند
[ ] مقیاس: اندازه‌ی نسبی اشیا واقعی است
[ ] لبه‌ها: ادغام‌های عجیب بین سوژه و پس‌زمینه نیست
```

**تست بزرگ‌نمایی:** روی ۲۰۰٪ نگاه کن، مخصوصاً به لبه‌ها، دست‌ها، و هر جایی که قرار است متن باشد.

---

## 3) دروازه‌ی بندانگشتی

مهم‌ترین دروازه. تصویر شاخص در فید، آرشیو و شبکه‌های اجتماعی کوچک دیده می‌شود.

```
[ ] در عرض ۱۵۰ پیکسل سوژه هنوز قابل تشخیص است
[ ] یک نقطه‌ی کانونی واضح وجود دارد، نه پنج تا
[ ] کنتراست سوژه با پس‌زمینه کافی است
[ ] در حالت سیاه‌وسفید هم خوانا است
```

```bash
# تست سریع
convert featured.webp -resize 150x thumb-test.png
convert featured.webp -colorspace Gray gray-test.png
```

اگر در ۱۵۰ پیکسل به لکه تبدیل شد: سوژه را بزرگ‌تر کن، جزئیات را کم کن، کنتراست را بالا ببر.

---

## 4) دروازه‌ی کلیشه

```
[ ] هیچ آیتمی از anti-cliche.md §1 در تصویر نیست
[ ] پالت از فهرست «پالت‌های خسته» نیست
[ ] ترکیب‌بندی یک تصمیم دارد، نه پیش‌فرض متقارن وسط‌چین
[ ] اگر صحنه‌ی ایرانی است، کلیشه‌ی شرق‌شناسانه ندارد
```

---

## 5) دروازه‌ی برند و هماهنگی

```
[ ] با بقیه‌ی تصاویر سایت یک خانواده‌ی بصری می‌سازد
[ ] پالت با برند سازگار است
[ ] مدیوم همان مدیومی است که برای سایت انتخاب شده
[ ] فضای منفی برای تیتر RTL در سمت درست قرار دارد
```

---

## 6) دروازه‌ی اخلاقی و حقوقی

```
[ ] هیچ لوگو، برند یا کاراکتر دارای حق کپی‌رایت دیده نمی‌شود
[ ] شباهت به شخص واقعی مشهور ندارد
[ ] اگر افرادی هستند، بازنمایی کلیشه‌ای یا تحقیرآمیز نیست
[ ] برای موضوع حساس (پزشکی، مالی، حقوقی) تصویر گمراه‌کننده نیست
[ ] افشای تولید با AI طبق سیاست انجام شده
```

---

## 7) دروازه‌ی فنی

```
[ ] ابعاد دقیقاً مطابق wordpress-sizing.md
[ ] فرمت WebP/AVIF
[ ] حجم زیر بودجه
[ ] نام فایل لاتین و توصیفی
[ ] alt نوشته شده
[ ] برش OG جداگانه ساخته شده (نه crop از 16:9)
```

---

## وقتی تصویر رد شد

| مشکل | اصلاح در پرامپت |
|---|---|
| خیلی شلوغ | یک سوژه بگذار، `minimal composition, single subject` |
| بی‌روح و مسطح | نور را مشخص کن: `single hard light from left` |
| شبیه استوک | مدیوم را عوض کن: `35mm film, visible grain` یا `risograph` |
| در بندانگشتی گم می‌شود | `extreme close-up`, `high contrast`, سوژه بزرگ‌تر |
| رنگ‌ها جیغ | `desaturated palette`, پالت را با نام رنگ بده |
| متن ناخواسته ظاهر شد | negative را تقویت کن: `no text, no lettering, no signage` |
| دست خراب | `no hands` یا کادر را عوض کن |
| ادعا دیده نمی‌شود | برگرد به `concept-engine.md` — مفهوم غلط است، نه پرامپت |

**قاعده:** بیش از سه بار همان مفهوم را دوباره تولید نکن. اگر سه بار جواب نداد، مفهوم مشکل دارد.
