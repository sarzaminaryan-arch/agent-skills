# سبک‌نامه‌ی فارسی — تایپوگرافی، نحو و رجیستر

---

## 1) نویسه‌های درست (سطح خطا)

| غلط | درست | یونیکد درست |
|---|---|---|
| `ي` عربی | `ی` فارسی | U+06CC |
| `ك` عربی | `ک` فارسی | U+06A9 |
| `٤ ٥ ٦` عربی | `۴ ۵ ۶` فارسی | U+06F0–U+06F9 |
| `,` | `،` ویرگول فارسی | U+060C |
| `;` | `؛` | U+061B |
| `?` | `؟` | U+061F |
| `"..."` | `«...»` | U+00AB / U+00BB |
| `...` | `…` | U+2026 |

بررسی سریع:

```bash
grep -nP '[يكﻻ٠-٩]' article.md
```

## 2) نیم‌فاصله (ZWNJ, U+200C)

نیم‌فاصله اختیاری نیست. جاهای الزامی:

- **می / نمی + فعل**: `می‌رود`، `نمی‌شود`، `می‌توانید` — نه `می رود`، نه `میرود`
- **جمع «ها»**: `سایت‌ها`، `کاربران` (این یکی چسبیده)، `فایل‌های`
- **پسوند «تر/ترین»**: `سریع‌تر`، `بزرگ‌ترین`
- **ضمایر پیوسته پس از «ه»**: `خانه‌ام`، `برنامه‌ات`
- **ترکیب‌های وصفی رایج**: `به‌روزرسانی`، `هم‌زمان`، `بی‌نهایت`، `پیش‌فرض`

**استثناها (چسبیده بنویس):** `کتابخانه`، `دانشگاه`، `همیشه`، `بااین‌حال` (با نیم‌فاصله)، `کارشناسان`

### مشکل رایج: نیم‌فاصله در وردپرس گم می‌شود
- ویرایشگر بصری گاهی ZWNJ را حذف می‌کند → همیشه در حالت کد (Code Editor) جای‌گذاری کن.
- در `.po`/`.mo` و در `esc_html_e()` نیم‌فاصله سالم می‌ماند.
- در URL و اسلاگ **هرگز** ZWNJ نگذار — اسلاگ را با `-` بنویس.
- تست: `grep -c $'\u200c' article.md` باید عدد معقولی بدهد (تقریباً ۲–۵٪ تعداد کلمات).

## 3) رجیستر — از اداری به معیار

| اداری/ماشینی | معیار طبیعی |
|---|---|
| می‌باشد | است |
| می‌گردد | می‌شود |
| نمی‌باشد | نیست |
| گردیده است | شده است |
| بدین وسیله | با این کار |
| فوق‌الذکر | همان که بالا گفتم |
| جهت انجام | برای انجام |
| در خصوص | درباره‌ی |
| مورد بررسی قرار گرفت | بررسی شد |
| اقدام به نصب نمود | نصب کرد |
| دارای سرعت بالا است | سریع است |

**قاعده‌ی «مورد ... قرار گرفت»:** این ساخت را در ۹۰٪ موارد با فعل ساده جایگزین کن. `مورد استفاده قرار می‌گیرد` → `استفاده می‌شود`.

## 4) نحو — نشانه‌های «ترجمه‌زدگی»

### ۴.۱ جمله‌های طولانیِ چندبندی
انگلیسی با relative clause جلو می‌رود؛ فارسی با جمله‌ی کوتاه.

❌ «افزونه‌ای که برای بهینه‌سازی تصاویر طراحی شده است و می‌تواند حجم فایل‌ها را کاهش دهد، در بهبود سرعت سایت که یکی از فاکتورهای رتبه‌بندی است مؤثر است.»

✅ «افزونه‌های فشرده‌سازی تصویر حجم فایل را کم می‌کنند. سایت سریع‌تر می‌شود، و سرعت یکی از فاکتورهای رتبه است.»

### ۴.۲ مجهول بی‌جا
❌ «کش فعال‌سازی گردید» → ✅ «کش را فعال کردم / کش فعال است»

### ۴.۳ ترتیب وصفی معکوس
❌ «یک راه‌حل کامل و جامع بهینه‌سازی» → ✅ «راهی برای بهینه‌سازی» (صفت‌های توخالی را حذف کن)

### ۴.۴ حرف تعریف انگلیسی
❌ «یک سایت وردپرسی نیاز به یک افزونه کش دارد» → ✅ «سایت وردپرسی به افزونه‌ی کش نیاز دارد»
«یک» را فقط وقتی بگذار که واقعاً «یک عدد» منظور است.

### ۴.۵ کسره‌ی اضافه
در متن رسمی، کسره را ننویس مگر ابهام ایجاد شود: `افزونه‌ی کش` (با ی) درست است؛ `مقاله‌ای` درست است.

## 5) اعداد

- در متن روان: اعداد فارسی `۱۲ افزونه`
- در کد، نسخه، و مسیر فایل: لاتین `WordPress 6.8`، `PHP 8.2`، `1.5s`
- درصد: `۴۰٪` (نویسه U+066A) یا `۴۰ درصد`
- در YAML front matter و اسلاگ: همیشه لاتین

## 6) واژگان فنی — ترجمه یا نویسه‌گردانی؟

| اصطلاح | توصیه |
|---|---|
| cache | «کش» (نویسه‌گردانی، جاافتاده) |
| plugin | «افزونه» |
| theme | «پوسته» یا «قالب» — یکی را انتخاب و در کل مقاله ثابت نگه دار |
| block | «بلوک» |
| post / page | «نوشته» / «برگه» (اصطلاح رسمی وردپرس فارسی) |
| widget | «ابزارک» |
| permalink | «پیوند یکتا» |
| hosting | «میزبانی» یا «هاست» |
| lazy load | «بارگذاری تنبل» یا همان lazy load داخل پرانتز |
| Core Web Vitals | همان لاتین + توضیح یک‌باره |

**قاعده:** بار اول اصطلاح را با معادل لاتین در پرانتز بیاور، بعد فقط فارسی: «پیوند یکتا (permalink)» → بعد از آن فقط «پیوند یکتا».

**قاعده‌ی مهم‌تر:** ترکیب فارسی/لاتین را در یک جمله قاطی نکن. یا `WordPress` یا `وردپرس` — در کل مقاله یکی.

## 7) راست‌به‌چپ در مارک‌داون و HTML

- فایل مارک‌داون فارسی: هیچ تگی لازم نیست، اما در خروجی HTML باید `dir="rtl" lang="fa-IR"` روی `<html>` باشد.
- کد و مسیر فایل را همیشه در backtick بگذار تا جهت نشکند: `wp-config.php`
- در جمله‌ی فارسی که با عبارت لاتین تمام می‌شود، نقطه را بعد از عبارت لاتین بگذار و اگر جهت شکست از `&rlm;` (U+200F) استفاده کن.
- جدول مارک‌داون فارسی در وردپرس ممکن است چپ‌چین رندر شود → در بلوک جدول وردپرس بساز، نه مارک‌داون خام.
