## نصب — ۳ دقیقه، همه از پیشخوان

```
۱. پیشخوان → نمایش → پوسته‌ها → افزودن پوسته → بارگذاری پوسته
۲. فایل zip را انتخاب کنید → «هم‌اکنون نصب کن»
۳. وردپرس می‌گوید «پوسته‌ای با همین نام موجود است» → «جایگزینی نسخه‌ی فعلی با بارگذاری‌شده»
۴. تمام. پوسته از قبل فعال است؛ نیازی به فعال‌سازی دوباره نیست.
```

اگر وردپرس اجازه‌ی جایگزینی نداد: اول پوسته‌ی مادر `sarzaminaryan` را موقتاً فعال
کنید، بعد فرزند را حذف و نسخه‌ی جدید را نصب و فعال کنید. تنظیمات سفارشی‌سازی
از بین نمی‌رود (در دیتابیس ذخیره است، نه در فایل قالب).

> **بازگشت:** فایل `sarzaminaryan-child.zip` که خودتان فرستادید همان نسخه‌ی ۲.۰.۱
> است. نگهش دارید؛ اگر چیزی خواستید برگردد، همان را دوباره نصب کنید.

## کلیدهای خاموشی

در `wp-config.php`:

```php
define( 'SA_CITATIONS', false );   // پانویس‌سازی خاموش؛ رفتار ۲.۰.۱ برمی‌گردد
```

در سفارشی‌سازی: **حالت دروازه = soft** → هیچ‌چیز مانع انتشار نیست، فقط هشدار.

و برای انتشار بی‌قیدوشرط، یک فیلتر:

```php
add_filter( 'sa_gate_blocking', '__return_empty_array' );
```

## آنچه از پروژه‌ی Iran Map برداشته شد (نسخه‌ی ۲.۲.۰)

خود قالب `iran-map` و افزونه‌ی `iran-regions` استفاده نشدند — `Requires PHP 8.0`،
نوع محتوای متفاوت (`region`) و ساختار موازی که با مدل داده‌ی شما تداخل می‌کرد.
**اما دو دارایی داخلش واقعاً ارزشمند بود و هر دو وصل شد:**

### ۱. داده‌ی ۳۱ استان — ۱۰۰٪ کامل

`regions.json` برای هر ۳۱ استان این‌ها را داشت و همه‌شان پر بودند:
مرکز، جمعیت، مساحت (km²)، اقلیم، فهرست همسایه‌ها، و مختصات.

نمونه‌گیری مختصات در برابر مقادیر شناخته‌شده:

| شهر | داده | واقعی | |
|---|---|---|---|
| کاشان | ۳۳٫۸۱ / ۵۱٫۲۹ | ۳۳٫۹۸ / ۵۱٫۴۳ | ✓ |
| تبریز | ۳۷٫۹۷ / ۴۶٫۳۷ | ۳۸٫۰۸ / ۴۶٫۲۹ | ✓ |
| یزد | ۳۱٫۸۸ / ۵۴٫۴۴ | ۳۱٫۹۰ / ۵۴٫۳۷ | ✓ |
| رشت | ۳۷٫۲۱ / ۴۹٫۶۵ | ۳۷٫۲۸ / ۴۹٫۵۸ | ✓ |

حالا جدول «اطلاعات کلیدی» کنار هر صفحه‌ی استان **خودکار پر می‌شود** — بدون
یک کلیک. با فیلتر `default_post_metadata`، یعنی فقط جایی که فیلد اصلاً در
دیتابیس نیست. هر چیزی که خودتان وارد کرده باشید دست نمی‌خورد.

از ۷۶۱ رکورد شهرستانی، ۲۸۳ تا بی‌نام بودند و حذف شدند؛ ۴۷۵ شهرستان با نام
فارسی و مختصات ماند. جمعیت و مساحتِ شهرستان‌ها در مبدأ خالی بود (۰٪) — آن
هنوز باید جمع شود.

### ۲. نقشه‌ی کلیک‌پذیر شهرستان‌ها — مهم‌ترین دستاورد این نسخه

۳۱ فایل SVG، مرز هر شهرستان یک `<path>` جدا با `data-slug` که دقیقاً نامک
وردپرسی شماست. ۲۸۶ مسیر خالی حذف شد، ۴۷۵ مسیر سالم ماند.

روی صفحه‌ی هر استان خودکار می‌آید:

- شهرستانِ **منتشرشده** → آبی، کلیک‌پذیر، لینک به صفحه‌اش
- شهرستانِ بدون صفحه → خاکستری، غیرقابل‌کلیک، بدون لینک

با انتشار هر شهرستان خودبه‌خود فعال می‌شود و هیچ ۴۰۴ ساخته نمی‌شود.
کد کوتاه هم هست: `[sa_county_map province="isfahan"]`

پوشش روی چهار استان منتشرشده:

| استان | شهرستان روی نقشه |
|---|---|
| آذربایجان شرقی | ۲۱ |
| اصفهان | ۲۸ |
| آذربایجان غربی | ۲۰ |
| اردبیل | ۱۲ |

در کل **۷۰ از ۸۲ شهرستان منتشرشده (۸۵٪)** روی نقشه‌اند.

**دوازده شهرستان در داده‌ی مبدأ نبودند** و خاکستری هم نمی‌آیند، چون اصلاً
مسیرشان وجود ندارد. مهم‌ترینشان **ارومیه** است — مرکز استان آذربایجان غربی.
بقیه: انگوت، آران و بیدگل، بوئین‌میاندشت، چاراویماق، فلاورجان، گیوی،
خور و بیابانک، میمه‌وزوان، سرعین، شاهین‌شهر و میمه، تیران و کرون.

این کمبود قابل رفع است (رسم دستی مسیر از روی مرزهای OSM)، ولی کار امروز نیست.
نقشه بدون آن‌ها هم کار می‌کند.
