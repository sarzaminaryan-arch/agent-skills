# لینک داخلی و خوشه‌ی موضوعی

---

## 1) چرا مهم است

لینک داخلی سه کار می‌کند: کشف صفحات توسط خزنده، انتقال اعتبار، و تعریف رابطه‌ی موضوعی. در سایت‌های فارسی معمولاً ضعیف‌ترین بخش سئو است — صدها مقاله که هیچ‌کدام به هم لینک نمی‌دهند.

---

## 2) ساختار pillar و cluster

```
                 ┌──────────────────────┐
                 │  صفحه‌ی مادر (pillar) │
                 │  «سرعت سایت وردپرس»  │
                 └──────────┬───────────┘
        ┌───────────┬───────┴───────┬────────────┐
        ▼           ▼               ▼            ▼
   کش صفحه     بهینه‌سازی تصویر   فونت فارسی    دیتابیس
        └───────────┴───────┬───────┴────────────┘
                  (خوشه‌ها به هم و به مادر لینک می‌دهند)
```

قواعد:
- هر مقاله‌ی خوشه **حتماً** به pillar لینک می‌دهد.
- pillar به همه‌ی خوشه‌ها لینک می‌دهد.
- خوشه‌ها به یکدیگر لینک می‌دهند وقتی واقعاً مرتبط‌اند.
- هیچ خوشه‌ای بدون لینک ورودی نماند.

---

## 3) انکرتکست فارسی

| بد | خوب |
|---|---|
| اینجا کلیک کنید | راهنمای کش وردپرس |
| بیشتر بخوانید | چرا فونت فارسی CLS می‌سازد |
| این مقاله | اندازه‌گیری TTFB با WP-CLI |
| https://example.ir/... | همان عنوان توصیفی |
| کش وردپرس کش وردپرس کش | کش وردپرس |

قواعد:
- انکر باید بگوید مقصد چیست، بدون خواندن جمله‌ی اطراف.
- تنوع داشته باش؛ صد لینک با انکر یکسان الگوی مصنوعی است.
- انکر ۲–۵ کلمه.
- انکر داخل جمله‌ی طبیعی، نه چسبیده به آخر بند.

**نکته‌ی RTL:** لینک‌های چسبیده در متن فارسی سخت‌تر تشخیص داده می‌شوند. زیرخط (`text-decoration: underline`) را در متن مقاله نگه دار، حذفش نکن.

## 4) قواعد کمّی

| سنجه | مقدار |
|---|---|
| لینک داخلی محتوایی در هر مقاله | ۳–۸ |
| لینک ورودی به هر صفحه‌ی مهم | ≥ ۳ |
| عمق کلیک از صفحه‌ی اصلی | حداکثر ۳ |
| صفحات یتیم (بدون لینک ورودی) | ۰ |
| لینک به یک صفحه از یک مقاله | ۱ بار (اولین رخداد) |

## 5) پیدا کردن صفحات یتیم

```bash
# همه‌ی URLهای منتشرشده
wp post list --post_type=post --post_status=publish --field=url > all-urls.txt

# جستجوی هر URL در محتوای بقیه
while read -r url; do
  slug=$(basename "$url")
  count=$(wp db query "SELECT COUNT(*) FROM wp_posts WHERE post_status='publish' AND post_content LIKE '%${slug}%';" --skip-column-names)
  if [ "$count" -le 0 ]; then echo "ORPHAN: $url"; fi
done < all-urls.txt
```

روش ساده‌تر: Screaming Frog یا گزارش `Links` در Search Console (`Internally linked pages` را صعودی مرتب کن).

## 6) لینک‌های شکسته و ریدایرکت‌شده

```bash
# بررسی سریع وضعیت لینک‌های داخلی
grep -oP 'href="https://example\.ir[^"]*"' page.html | sort -u | \
  sed 's/href="//;s/"//' | while read -r u; do
    code=$(curl -s -o /dev/null -w '%{http_code}' "$u")
    [ "$code" != "200" ] && echo "$code  $u"
  done
```

- لینک داخلی هرگز نباید به ریدایرکت بخورد. مستقیم به URL نهایی لینک بده.
- ۴۰۴ داخلی را یا اصلاح کن یا حذف.

## 7) لینک‌های خودکار — احتیاط

افزونه‌هایی که خودکار کلیدواژه را لینک می‌کنند (Internal Link Juicer و مشابه) در فارسی خطرناک‌اند:

- با نیم‌فاصله و واریانت املایی درست کار نمی‌کنند.
- گاهی وسط کلمه لینک می‌سازند.
- انکرهای یکسان انبوه تولید می‌کنند.

اگر استفاده می‌کنی: سقف تعداد لینک در هر مقاله را بگذار، و خروجی را روی ۱۰ مقاله دستی بررسی کن.

---

## 8) ناوبری و فوتر

- منوی اصلی: حداکثر ۷ آیتم سطح اول. منوی مگا با ۶۰ لینک، اعتبار را رقیق می‌کند.
- فوتر: لینک به صفحات مهم، نه به همه‌ی برچسب‌ها.
- breadcrumb قابل مشاهده روی هر صفحه‌ی داخلی + اسکیمای متناظر.
- ویجت «نوشته‌های مرتبط» فقط اگر واقعاً مرتبط باشد؛ خروجی تصادفی بی‌فایده است.
