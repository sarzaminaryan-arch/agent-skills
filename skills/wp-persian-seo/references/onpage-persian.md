# بهینه‌سازی درون‌صفحه‌ای فارسی

---

## 1) تگ عنوان (Title)

**مشکل فارسی:** گوگل عنوان را بر اساس **عرض پیکسلی** می‌برد، نه تعداد نویسه. حروف فارسی باریک‌ترند، پس معمولاً می‌توانی کمی بیشتر از ۶۰ نویسه‌ی انگلیسی جا بدهی — اما «ط»، «ک» کشیده و اعداد عرض بیشتری می‌گیرند.

| قاعده | مقدار |
|---|---|
| طول امن | ۵۰–۶۰ نویسه‌ی فارسی |
| حداکثر مطلق | ۶۵ نویسه |
| جای کلیدواژه | نزدیک شروع (در RTL یعنی سمت راست) |
| نام برند | آخر، با `|` یا `-` |
| عدد | جذب کلیک را بالا می‌برد: «۷ روش…» |
| تکرار | عنوان تکراری بین صفحات = مشکل |

```
✅ راهنمای کامل کش وردپرس برای سایت‌های فارسی | نام برند
❌ کش وردپرس، بهینه سازی وردپرس، سرعت وردپرس، افزونه کش وردپرس
❌ صفحه اصلی | نام برند
```

**تست بریدگی:** عنوان را در یک ابزار پیش‌نمایش SERP بگذار و مطمئن شو وسط کلمه بریده نمی‌شود. بریدگی وسط کلمه‌ی فارسی خیلی بدتر از انگلیسی دیده می‌شود چون حروف به هم چسبیده‌اند.

## 2) توضیحات متا

| قاعده | مقدار |
|---|---|
| طول | ۱۴۰–۱۶۰ نویسه |
| محتوا | **دلیل کلیک**، نه خلاصه‌ی مقاله |
| کلیدواژه | یک بار، طبیعی (در SERP بولد می‌شود) |
| فعل | امری یا دعوت‌کننده |
| ممنوع | کپی جمله‌ی اول مقاله |

```
✅ چرا افزونه‌ی کش روی صفحه‌های لاگین کار نمی‌کند و به‌جایش چه باید کرد. با دستورهای WP-CLI برای اندازه‌گیری واقعی.
❌ در این مقاله به بررسی کش در وردپرس می‌پردازیم و نکات مهم آن را بیان می‌کنیم.
```

اگر توضیحات متا ننویسی، گوگل از متن صفحه می‌سازد — که گاهی بهتر از یک توضیح بد است، اما روی صفحات مهم خودت بنویس.

## 3) ساختار تیترها

```
[ ] دقیقاً یک H1 در صفحه
[ ] H1 با عنوان SEO یکی نیست (متفاوت اما هم‌راستا)
[ ] H1 نیت جستجو را منعکس می‌کند
[ ] ترتیب H2 → H3 بدون پرش
[ ] هیچ H2 با نام «مقدمه» یا «نتیجه‌گیری»
[ ] هر H2 حدوداً با یک کلیدواژه‌ی دم‌بلند هم‌راستا است
[ ] تیترها بدون خواندن متن، مسیر مقاله را می‌گویند
```

مثال ساختار برای «چرا سایتم کند است»:

```
H1: چرا سایت وردپرسی فارسی من کند است
  H2: اول اندازه بگیرید: سه عددی که باید بدانید
  H2: فونت فارسی، متهم اول
  H2: افزونه‌های متداخل
  H2: وقتی مشکل از هاست است نه از کد
```

---

## 4) صد کلمه‌ی اول

- کلیدواژه‌ی اصلی یک بار، طبیعی.
- پاسخ مستقیم به نیت کوئری. اگر کوئری «خطای ۵۰۰» است، در همین ۱۰۰ کلمه بگو معمولاً از چیست.
- برای شانس فیچر اسنیپت: یک تعریف ۲ جمله‌ای یا فهرست کوتاه در ابتدای بخش مربوطه.
- بدون مقدمه‌چینی. `content-humanizer/references/openings.md` را بخوان.

---

## 5) فیچر اسنیپت فارسی

گوگل فارسی هم اسنیپت می‌دهد. سه فرمت:

**بند (paragraph)** — تعریف در ۴۰–۶۰ کلمه، بلافاصله بعد از یک H2 سؤالی:

```markdown
## کش وردپرس چیست؟

کش وردپرس یعنی ذخیره‌ی نسخه‌ی آماده‌ی صفحه تا در درخواست بعدی، سرور
دوباره آن را از صفر نسازد. نتیجه‌اش کاهش زمان پاسخ سرور و مصرف کمتر
منابع است. کش برای بازدیدکننده‌ی مهمان کار می‌کند، نه برای کاربر لاگین‌شده.
```

**فهرست** — H2 سؤالی + فهرست شماره‌دار با آیتم‌های کوتاه.

**جدول** — H2 + جدول با سرستون واضح، حداکثر ۴ ستون.

قواعد: جواب را **بلافاصله** بعد از تیتر بگذار، نه بعد از یک بند مقدمه.

## 7) لینک داخلی

```
[ ] حداقل ۳ لینک داخلی محتوایی در متن
[ ] انکرتکست توصیفی فارسی — نه «اینجا کلیک کنید»، نه URL خام
[ ] لینک به صفحه‌ی pillar مرتبط
[ ] بدون لینک شکسته
[ ] لینک‌ها به URL نهایی، نه از طریق ریدایرکت
```

جزئیات در `references/internal-linking.md`.

---

## 8) لینک خارجی

- به منبع معتبر لینک بده وقتی ادعای عددی می‌کنی. این هم برای کاربر خوب است هم برای E-E-A-T.
- لینک خارجی `target="_blank"` با `rel="noopener"`.
- لینک تبلیغاتی/همکاری در فروش: `rel="sponsored"`.
- لینک به محتوای غیرقابل‌اعتماد (نظرات، انجمن): `rel="ugc"` یا `nofollow`.

## 9) E-E-A-T برای سایت فارسی

گوگل برای محتوای فارسی هم سیگنال اعتبار می‌خواهد:

```
[ ] صفحه‌ی «درباره ما» واقعی با نام و سابقه
[ ] باکس نویسنده با نام واقعی و تخصص
[ ] تاریخ انتشار و تاریخ به‌روزرسانی قابل مشاهده
[ ] راه تماس واقعی (نه فقط فرم)
[ ] در حوزه‌ی YMYL (پزشکی، مالی، حقوقی) مرجع و منبع الزامی است
[ ] نماد اعتماد الکترونیکی برای فروشگاه (اینماد) — سیگنال اعتماد کاربری
```

[ ] یک H1، سلسله‌مراتب بدون پرش
[ ] کلیدواژه در ۱۰۰ کلمه‌ی اول، طبیعی
[ ] یک بخش با فرمت مناسب فیچر اسنیپت
[ ] اسلاگ کوتاه، بدون حرف اضافه، مطابق سیاست سایت
[ ] تصاویر بهینه با alt فارسی
[ ] ≥ ۳ لینک داخلی با انکر توصیفی
[ ] منابع خارجی برای ادعاهای عددی
[ ] اسکیما مطابق references/schema-persian.md
