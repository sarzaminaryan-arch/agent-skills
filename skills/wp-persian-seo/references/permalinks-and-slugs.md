# پیوند یکتا و اسلاگ فارسی

---

## 1) ساختار پیوند یکتا

| ساختار | توصیه |
|---|---|
| `/%postname%/` | ✅ پیش‌فرض توصیه‌شده برای بلاگ |
| `/%category%/%postname%/` | ⚠️ فقط اگر دسته‌بندی پایدار است؛ تغییر دسته = تغییر URL |
| `/%year%/%monthnum%/%postname%/` | ❌ محتوا را قدیمی نشان می‌دهد |
| `/?p=123` | ❌ |
| `/%postname%.html` | ❌ بدون دلیل |

در `Settings → Permalinks` یا:

```bash
wp rewrite structure '/%postname%/' --hard
wp rewrite flush --hard
```

**نکته:** اگر سایت روی هاست ایرانی با LiteSpeed یا nginx است، بعد از تغییر ساختار، قوانین rewrite را در پنل هاست هم بررسی کن؛ `flush` همیشه کافی نیست.

## 2) اسلاگ فارسی یا لاتین؟

این مهم‌ترین تصمیم است. هر دو کار می‌کنند؛ ناسازگاری است که ضرر می‌زند.

### اسلاگ فارسی — `example.ir/آموزش-سئو-وردپرس/`

**مزایا**
- گوگل آن را رمزگشایی و در نتایج فارسی نمایش می‌دهد
- کاربر فارسی‌زبان URL را می‌فهمد
- کلیدواژه در URL

**معایب**
- در کپی/پیست به `%D8%A2%D9%85%D9%88%D8%B2%D8%B4-...` تبدیل می‌شود
- در تلگرام، واتس‌اپ و ایمیل زشت و گاهی شکسته می‌شود
- بعضی CDNها و افزونه‌های کش با URL درصدی مشکل دارند
- طول URL در percent-encoding سه برابر می‌شود (محدودیت ۲۰۰۰ نویسه‌ای در بعضی سرورها)
- در لاگ سرور و ابزارهای تحلیل ناخواناست

### اسلاگ لاتین — `example.ir/wordpress-seo-guide/`

**مزایا**
- همه‌جا تمیز، قابل اشتراک، قابل خواندن در لاگ
- بدون مشکل در CDN و کش
- کوتاه

**معایب**
- کلیدواژه‌ی فارسی در URL نیست (اثر رتبه‌ای آن امروز ناچیز است)

### توصیه

| نوع سایت | توصیه |
|---|---|
| بلاگ فارسی با مخاطب داخلی، اشتراک‌گذاری زیاد در پیام‌رسان | **لاتین ترانویسی‌شده** |
| سایت خبری با حجم بالا | لاتین |
| فروشگاه | لاتین برای محصول، فارسی برای دسته اگر می‌خواهی |
| سایت موجود که با اسلاگ فارسی رتبه دارد | **دست نزن** |

**قاعده‌ی اصلی: یکدستی.** نصف سایت فارسی و نصف لاتین بدترین حالت است.

## 3) نویسه‌های ممنوع در اسلاگ

```
❌ نیم‌فاصله (U+200C) — هرگز
❌ ي ك عربی
❌ ارقام فارسی ۱۲۳ (از 123 لاتین استفاده کن)
❌ حروف اضافه: از، به، با، در، برای، و، که
❌ بیش از ۵ کلمه
❌ تاریخ در اسلاگ مگر محتوا زمان‌محور باشد
```

پاک‌سازی ZWNJ از اسلاگ‌های موجود:

```bash
# فهرست اسلاگ‌های آلوده
wp db query "SELECT ID, post_name FROM wp_posts WHERE post_name LIKE '%\\\\u200c%' OR post_name LIKE '%ي%' OR post_name LIKE '%ك%';"

# پیش از هر تغییر
wp db export backup-before-slug-fix.sql
```

اصلاح دسته‌جمعی نویسه‌های عربی در **محتوا** (نه اسلاگ):

```bash
wp search-replace 'ي' 'ی' wp_posts wp_postmeta --precise --all-tables-with-prefix --dry-run
wp search-replace 'ك' 'ک' wp_posts wp_postmeta --precise --all-tables-with-prefix --dry-run
# بررسی خروجی، بعد بدون --dry-run اجرا کن
```

⚠️ `--dry-run` را حذف نکن تا خروجی را ندیده‌ای. جزئیات ایمنی در `wp-wpcli-and-ops`.

## 4) تغییر اسلاگ روی سایت ایندکس‌شده

**هرگز بدون ریدایرکت.**

1. فهرست URLهای فعلی را از Search Console یا سایت‌مپ بگیر.
2. نگاشت قدیم → جدید بساز.
3. ریدایرکت ۳۰۱ بگذار (افزونه‌ی Redirection یا در سطح سرور).
4. سایت‌مپ را دوباره ارسال کن.
5. لینک‌های داخلی را به URL جدید به‌روزرسانی کن (نه از طریق ریدایرکت).
6. چند هفته `Coverage` را رصد کن.

```apache
# .htaccess — نمونه
Redirect 301 /آموزش-سئو/ /wordpress-seo-guide/
```

```nginx
# nginx
location = /%D8%A2%D9%85%D9%88%D8%B2%D8%B4-%D8%B3%D8%A6%D9%88/ {
    return 301 /wordpress-seo-guide/;
}
```

**بودجه‌ی ریدایرکت:** اگر بیش از چند صد URL داری، زنجیره‌ی ریدایرکت و افت موقت ترافیک را در نظر بگیر. تغییر دسته‌جمعی اسلاگ روی سایت پرترافیک، پروژه است نه یک کار ده‌دقیقه‌ای.

## 5) دسته‌ها و برچسب‌ها

```bash
# پایه‌ی دسته را حذف کن یا فارسی نکن
wp option update category_base 'category'
wp option update tag_base 'tag'
```

- برچسب‌های کم‌محتوا را `noindex` کن. سایت‌های فارسی معمولاً صدها برچسب تک‌نوشته دارند که محتوای نازک تولید می‌کنند.
- در Yoast: `Search Appearance → Taxonomies → Tags → Show in search results: Off`
- در Rank Math: `Titles & Meta → Taxonomies → Tags → Robots: noindex`

---

## 6) تاریخ شمسی و URL

اگر از افزونه‌ی تاریخ شمسی استفاده می‌کنی:

- تاریخ شمسی را **در URL نگذار** — بایگانی‌های تاریخی گوگل را گیج می‌کند.
- تاریخ نمایشی می‌تواند شمسی باشد؛ `datePublished` در اسکیما و در `<time datetime="">` باید **میلادی ISO 8601** باشد.
- جزئیات در `references/schema-persian.md` §5.
