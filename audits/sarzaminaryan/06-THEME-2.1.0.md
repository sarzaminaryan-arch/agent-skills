## نصب — ۳ دقیقه، همه از پیشخوان

```
۱. پیشخوان → نمایش → پوسته‌ها → افزودن پوسته → بارگذاری پوسته
۲. فایل zip را انتخاب کنید → «هم‌اکنون نصب کن»
۳. وردپرس می‌گوید «پوسته‌ای با همین نام موجود است» → «جایگزینی نسخه‌ی فعلی با بارگذاری‌شده»
۴. تمام. پوسته از قبل فعال است؛ نیازی به فعال‌سازی دوباره نیست.
```

اگر وردپرس اجازه‌ی جایگزینی نداد: اول پوسته‌ی مادر `sarzaminaryan` را موقتاً فعال
کنید، بعد فرزند را حذف و نسخه‌ی جدید را نصب و فعال کنید. تنظیمات سفارشی‌سازی
از بین نمی‌رود (در دیتابیس ذخیره است، نه در فایل قالب).

## کلیدهای خاموشی

در `wp-config.php`:

```php
define( 'SA_CITATIONS', false );   // پانویس‌سازی خاموش؛ رفتار ۲.۰.۱ برمی‌گردد
```

در سفارشی‌سازی: **حالت دروازه = soft** → هیچ‌چیز مانع انتشار نیست، فقط هشدار.

و برای انتشار بی‌قیدوشرط، یک فیلتر:

```php
add_filter( 'sa_gate_blocking', '__return_empty_array' );
```

## یک دارایی که در `iran-map.zip` پیدا شد

قالب `iran-map` به‌عنوان قالب کار نمی‌کند (`Requires PHP 8.0`، ساختار جدا، CPT
متفاوت `region`) و ارزش زنده‌کردن ندارد. **اما یک چیز داخلش هست که ارزشمند است:**

```
assets/svg/counties/*.svg   →  ۳۱ نقشه‌ی شهرستانی، یکی برای هر استان
assets/svg/iran-provinces.svg
assets/svg/regions.json
```

هر فایل، مرزهای شهرستان‌های یک استان را به‌صورت `<path>` جدا دارد، با
`data-slug` که **دقیقاً همان نامک وردپرسی شهرستان است**:

```html
<path id="county-ardabil-ardabil-city" data-slug="ardabil-city"
      data-parent="ardabil" class="county" d="…" />
```

این یعنی می‌شود در صفحه‌ی هر استان یک **نقشه‌ی کلیک‌پذیر شهرستان‌ها** گذاشت که
هر شهرستانِ منتشرشده لینک شود و بقیه خاکستری بماند. دقیقاً همان چیزی که در
`02-RULEBOOK.md` بخش ۲ گفتم صفحه‌ی استان باید باشد: **هاب**، نه مقاله.

و این چیزی است که کجارو و علی‌بابا ندارند.

**دو نکته پیش از استفاده:**

1. چند شهرستان در فایل‌ها خالی مانده‌اند (`data-slug=""` و `d=""`) — باید پاک شوند.
2. چند نامک با نامک‌های شما فرق دارد و نیاز به نگاشت دارد:
   `kahlkhal` → `khalkhal` · `bilehsavar` → `bileh-savar` · `meshkinshahr` → `meshgin-shahr`

این کار در گروه سوم چک‌لیست (`05-CHECKLIST.md`) جا می‌گیرد، نه الان.
اول ۲.۱.۰ را نصب کنید و ۲۷ استان را منتشر کنید.
