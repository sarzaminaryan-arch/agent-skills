# تصویر شاخص شهرستان‌ها — سیستم کارت مورس

> تصمیم مالک، ۱۴۰۵/۰۷/۰۸: سبک کارت‌ها از «تصویرسازی منظره + نام» به یک سیستم
> مینیمال تغییر کرد. این سند، طراحی و روش ساخت را ثبت می‌کند تا بازتولیدپذیر
> بماند و کسی مجبور نباشد دوباره کشفش کند.

## مسئله

۸۲ کارت موجود، هر کدام یک تصویرسازی جداگانه‌اند: منظره‌ی آبرنگی + نام فارسی +
نام انگلیسی روی زمینه‌ی چوب کرم. زیبا، ولی:

- **برای ۴۰۰ شهرستان تکرارپذیر نیست** — هر کدام یک تصویرسازی تازه می‌خواهد
- **حجم:** ۱۳۴ تا ۲۲۸ کیلوبایت برای هر کارت
- **متن را مدل تصویر نوشته** — یعنی هر کارت باید چشمی بررسی شود که حروف فارسی
  نشکسته باشند

## طراحی تازه

```
┌──────────────────────────────────────────────┐
│ ░░░                                          │
│ ░░░░                                         │
│ ░░░░░        (سفید خالی)                     │
│ ░░░░                    دورود — لرستان  ▮••  │
│ ░░░                                          │
└──────────────────────────────────────────────┘
  زمینه‌ی سفید        متن طوسی-مشکی      نشانه‌ی رنگی
  با برجستگی        فونت Vazirmatn      مورس حرف اول
```

سه جزء، نه بیشتر:

| جزء | قاعده |
|---|---|
| **زمینه** | سفید، با برجستگی نقطه و شیار (بدون طبیعت). سه نسخه برای تنوع. |
| **نشانه** | کد مورس نخستین حرفِ نام شهرستان. خط = میله‌ی عمودی، نقطه = مربع. راست‌به‌چپ. |
| **رنگ** | یک رنگ کاملاً اشباع برای هر استان، از پالت ۳۱ رنگی. |
| **متن** | «نام شهرستان — نام استان»، Vazirmatn Bold، `#12161d`. |

### چرا مورس

نشانه تصادفی نیست؛ از خودِ نام درمی‌آید. «دورود» با «د» شروع می‌شود، مورسِ «د»
برابر `-..` است، پس نشانه می‌شود یک میله و دو مربع. قابل‌توضیح، قابل‌تکرار،
و برای هر شهرستانی خودبه‌خود تعیین می‌شود.

**تکرار پذیرفته شده است.** «کاشان» و «کوهپایه» هر دو با «ک» شروع می‌شوند و
نشانه‌شان یکی است. مالک این را پذیرفت؛ رنگ استان و نام، تمایز را می‌سازند.

## کشف کلیدی: متن را مدل تصویر نمی‌نویسد

مهم‌ترین نکته‌ی فنی این سیستم.

مدل‌های تولید تصویر حروف فارسی را می‌شکنند، جدا می‌نویسند یا وارونه می‌چینند.
برای طراحی مینیمالی که **متن، خودِ طراحی است**، این ریسک پذیرفتنی نیست.

راه‌حل — متن در مرحله‌ی دوم و با ابزار قطعی روی تصویر می‌نشیند:

```
۱. فونت Vazirmatn-Bold.woff2 از قالب مادرِ خود سایت
۲. تبدیل woff2 → ttf با fontTools
   (Vazirmatn شامل ۱۴۱ گلیف Presentation Forms است — بررسی شد)
۳. شکل‌دهی متن با arabic_reshaper + python-bidi
   «دورود — لرستان»  →  «ﻥﺎﺘﺳﺮﻟ — ﺩﻭﺭﻭﺩ»
۴. رندر با ImageMagick و همان فونت
```

نتیجه:

- حروف همیشه درست، چسبیده و راست‌چین
- تایپوگرافی هر ۴۰۰ کارت پیکسل‌به‌پیکسل یکسان
- **نیازی به بازبینی چشمی نیست**
- همان فونتی که متن مقاله‌ها با آن خوانده می‌شود

> ImageMagick این محیط با `pango` ساخته شده ولی کدک `pango:` ثبت نشده بود؛
> به همین دلیل مسیر reshaper + annotate انتخاب شد. اگر جایی `pango:` در
> دسترس بود، همان ساده‌تر است.

### کاربرد

```bash
pip install arabic-reshaper python-bidi        # یک‌بار

# تکی
python3 make_card.py --city دورود --province لرستان \
                     --color '#e02020' --out ../out/dorud.webp

# کل یک استان
python3 make_card.py --batch alborz.json
```

قالب `batch.json`:

```json
[
  {"city":"کرج","province":"البرز","color":"#0b63f6","out":"../out/karaj.webp"},
  {"city":"طالقان","province":"البرز","color":"#0b63f6","out":"../out/taleghan.webp"}
]
```

### هندسه‌ی تأییدشده

| پارامتر | مقدار | جای تغییر |
|---|---|---|
| بوم | ۱۶۷۲×۹۴۱ | `W, H` |
| اندازه‌ی متن | ۱۱۸ | `SIZES['large']['pt']` |
| میله‌ی مورس | ۲۸×۱۳۲ | `SIZES['large']` |
| مربع مورس | ۳۲ | همان |
| حاشیه‌ی راست | ۱۶۵ | `RIGHT_MARGIN` |
| خط پایه | ۰٫۶۳ ارتفاع | `BASE_RATIO` |
| رنگ متن | `#12161d` | `INK` |

سه اندازه‌ی آماده: `small` · `medium` · `large` (پیش‌فرض و تأییدشده).

## زمینه‌ها

زمینه‌ها با تولید تصویر ساخته می‌شوند، **بدون هیچ متنی**. الگوی پرامپت:

> سفید خالص، برجستگی بسیار کم‌عمق هم‌رنگِ کاغذ، میدان نقطه‌های ریز منظم +
> چند شیار مستقیم موازی، متمرکز در چپ و محوشونده به سمت مرکز. **دو سوم راستِ
> کادر کاملاً خالی** برای متن. بدون طبیعت، بدون برگ، بدون متن، بدون رنگ.

نکته‌ی مهم پرامپت: تأکید بر خالی‌بودن سمت راست. بدون آن، بافت زیر متن می‌افتد.

**وضعیت:** یک زمینه ساخته شده (`bg1.webp`). دو زمینه‌ی دیگر (شیار افقی،
کمان نقطه) در نوبت است.

## اتصال به خط لوله‌ی موجود

بسته‌ی درون‌ریز شهرستان (`sa-city-importer-<province>/data/<province>.json`)
برای هر شهرستان چنین کلیدی دارد:

```json
"image": {
  "file":   "assets/counties/taleghan.webp",
  "source": "assets/featured/counties/alborz/taleghan.webp",
  "mime":   "image/webp",
  "alt":    "شهرستان طالقان",
  "sha1":   "…"
}
```

یعنی کارت‌های تولیدشده مستقیم در همان مسیر می‌نشینند و افزونه هنگام
درون‌ریزی آن‌ها را به‌عنوان تصویر شاخص ثبت می‌کند. هیچ مرحله‌ی دستی لازم نیست.
