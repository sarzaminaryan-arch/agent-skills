# متن‌نویسی فارسی صفحه‌ی اول

متن صفحه‌ی اول با متن مقاله فرق دارد: کوتاه‌تر، مشخص‌تر، اقدام‌محورتر.
برای متن بلند مقاله، `content-humanizer` را ببین.

---

## 1) تیتر قهرمان

**قواعد سخت:**
- حداکثر ۹ کلمه
- یک اسم مشخص و یک فعل داشته باشد
- بگوید چه چیزی برای چه کسی
- بدون «بهترین»، «حرفه‌ای‌ترین»، «پیشرو»، «برتر»

| ❌ | ✅ |
|---|---|
| به وبسایت ما خوش آمدید | سایت فروشگاهی‌ات را در دو هفته راه بینداز |
| ارائه‌دهنده‌ی بهترین خدمات دیجیتال مارکتینگ | فروش فروشگاه‌های اینترنتی را با سئو بالا می‌بریم |
| راهکار جامع مدیریت کسب‌وکار شما | حسابداری فروشگاهت را از اکسل نجات بده |
| ما با شما هستیم | قالب وردپرس فارسی، سبک و سریع |
| خلاقیت، نوآوری، کیفیت | طراحی سایت برای کلینیک‌های دندان‌پزشکی |

**سه الگوی امن:**

1. **[نتیجه] برای [مخاطب]** — «سایت سریع برای فروشگاه‌های کوچک»
2. **[فعل] [چیز] بدون [درد]** — «فروشگاهت را راه بینداز بدون دانش فنی»
3. **[ادعای مشخص]** — «بارگذاری زیر یک ثانیه، روی هاست ایرانی»

---

## 2) زیرتیتر

یک جمله، حداکثر ۲۰ کلمه. کاری که تیتر نکرد را انجام می‌دهد: «چطور» یا «برای که».

```
تیتر:    سایت فروشگاهی‌ات را در دو هفته راه بینداز
زیرتیتر: طراحی، محصول‌گذاری و اتصال درگاه پرداخت — همه با هم، بدون نیاز به تیم فنی.
```

**حذف کن:** «ما با سال‌ها تجربه…»، «تیم متخصص ما…» — درباره‌ی خودت حرف نزن.

---

## 3) متن دکمه (CTA)

| ❌ | ✅ |
|---|---|
| بیشتر بدانید | ببین چطور کار می‌کند |
| کلیک کنید | مشاوره رایگان بگیر |
| ارسال | درخواستم را بفرست |
| ثبت نام | حساب رایگان بساز |
| تماس با ما | وقت تماس بگذار |
| مشاهده | محصولات را ببین |
| خرید | همین حالا بخر |

قواعد:
- فعل امری، دوم‌شخص
- مشخص کند چه اتفاقی می‌افتد
- ۲–۴ کلمه
- ریسک را کم کن: «رایگان»، «بدون تعهد»، «لغو در هر زمان» — اگر واقعی است
- اقدام ثانویه باید بصری و متنی ضعیف‌تر باشد

**زیرمتن دکمه** (ریزمتن) اضطراب را کم می‌کند:
```
[ حساب رایگان بساز ]
بدون کارت بانکی · لغو در هر زمان
```

## 4) عنوان بخش‌ها

عنوان بخش باید محتوا را بگوید، نه برچسب عمومی بزند.

| ❌ | ✅ |
|---|---|
| خدمات ما | سه کاری که برایت انجام می‌دهیم |
| درباره ما | چرا این کار را شروع کردیم |
| مشتریان ما | نتیجه‌ای که برای مشتری‌ها گرفتیم |
| ویژگی‌ها | چه چیزی این را متفاوت می‌کند |
| نظرات | چیزی که مشتری‌ها می‌گویند |
| تماس با ما | بیایید شروع کنیم |
| سوالات متداول | سوالاتی که قبل از خرید می‌پرسند |

## 5) ویژگی در برابر سود

بازدیدکننده به قابلیت اهمیت نمی‌دهد؛ به نتیجه‌اش اهمیت می‌دهد.

| ویژگی | سود |
|---|---|
| پشتیبانی از CDN | صفحه‌ها برای کاربر شهرستانی هم سریع باز می‌شوند |
| پنل مدیریت اختصاصی | بدون تماس با ما، خودت محصول اضافه می‌کنی |
| کدنویسی استاندارد | سال بعد که خواستی توسعه بدهی، گیر نمی‌کنی |
| ۹۹.۹٪ آپ‌تایم | سایتت وسط کمپین پایین نمی‌آید |
| طراحی ریسپانسیو | روی موبایل هم درست دیده می‌شود (۸۰٪ مشتری‌هایت) |

**الگو:** ویژگی → «یعنی» → سود. بعد فقط سود را بنویس.

## 6) اعداد

- عدد مشخص > عدد گرد. «۳۴۷ پروژه» باورپذیرتر از «+۳۰۰ پروژه» است.
- عدد فارسی در متن نمایشی: «۱۲ روز»
- عدد لاتین در نسخه، کد، و مشخصات فنی: `PHP 8.2`
- قیمت: واحد را ثابت نگه دار. «۲٬۵۰۰٬۰۰۰ تومان» با جداکننده.
- **هرگز عدد نساز.** اگر آمار نداری، بخش آمار را حذف کن.

## 7) لحن

| نوع سایت | لحن |
|---|---|
| خدماتی B2B | محترمانه‌ی مستقیم، دوم‌شخص جمع «شما» |
| محصول برای توسعه‌دهنده | خودمانی، دوم‌شخص مفرد «تو» |
| فروشگاه عمومی | گرم و ساده، «شما» |
| بلاگ شخصی | اول‌شخص، صمیمی |
| پزشکی/حقوقی | رسمی، دقیق، بدون شوخی |

**قاعده:** یکی را انتخاب کن و در کل سایت ثابت نگه دار. مخلوط «شما» و «تو» در یک صفحه، غیرحرفه‌ای به‌نظر می‌رسد.

## 8) عبارات ممنوع در صفحه‌ی اول

```
به وبسایت ما خوش آمدید
با سال‌ها تجربه در زمینه‌ی...
ما بهترین هستیم
راهکار جامع و یکپارچه
تیم متخصص و مجرب ما
رضایت مشتری اولویت ماست
با ما در ارتباط باشید
جهت کسب اطلاعات بیشتر
همین حالا اقدام کنید (بدون گفتن چه اقدامی)
کیفیت، سرعت، قیمت مناسب
نوآوری در خدمت شما
```

فهرست کامل و دلایل در `content-humanizer/references/ai-tells.md` §1.

## 9) ریزمتن (Microcopy)

جزئیات کوچکی که تبدیل را بالا می‌برند:

| جا | متن |
|---|---|
| زیر فرم | «معمولاً ظرف ۲ ساعت کاری جواب می‌دهیم» |
| زیر دکمه‌ی خرید | «۷ روز ضمانت بازگشت وجه» |
| کنار ایمیل | «ایمیلت را به کسی نمی‌دهیم» |
| فرم خالی | «اولین سؤالت را بپرس» |
| خطای فرم | «شماره باید ۱۱ رقم باشد» — نه «خطا» |
| در حال ارسال | «در حال ارسال…» |
| موفقیت | «پیامت رسید. تا ۲ ساعت دیگر جواب می‌دهیم.» |

**قاعده:** هیچ‌وقت «خطا» تنها ننویس. بگو چه چیزی غلط است و چطور درستش کند.

## 11) بین‌المللی‌سازی

```php
// همه‌ی رشته‌ها ترجمه‌پذیر و escape شده
esc_html_e( 'مشاوره رایگان بگیر', 'my-theme' );

printf(
    /* translators: %s: تعداد پروژه */
    esc_html__( '%s پروژه از سال ۱۳۹۸', 'my-theme' ),
    esc_html( number_format_i18n( 347 ) )
);
```

- هرگز رشته را مستقیم در مارک‌آپ ننویس.
- `number_format_i18n()` برای اعداد.
- در فایل پترن، رشته‌ها با `esc_html_e()` داخل PHP یا با `<?php esc_html_e() ?>` در مارک‌آپ.
- نیم‌فاصله در فایل `.po` سالم می‌ماند.

```
[ ] تیتر hero زیر ۹ کلمه و مشخص است

[ ] یک CTA اصلی با فعل مشخص
[ ] عنوان همه‌ی بخش‌ها محتوامحور است، نه برچسب عمومی
[ ] همه‌ی ویژگی‌ها به سود ترجمه شده‌اند
[ ] هیچ عدد یا نظر جعلی نیست
[ ] لحن در کل صفحه یکدست است
[ ] هیچ عبارت ممنوعی نمانده
[ ] ریزمتن برای فرم‌ها و دکمه‌ها نوشته شده
[ ] همه‌ی رشته‌ها escape و ترجمه‌پذیرند
[ ] تایپوگرافی فارسی درست است
```
