# Link economy — where a page sends its weight

## §1 The ratio

Count every anchor in the body of every page in the corpus, split by destination:

```
external links  :  links leaving the domain
internal links  :  links to other pages on the domain
```

The ratio tells you what the corpus is *for*.

| external : internal | What it means |
|---|---|
| ≤ 0.2 : 1 | Healthy editorial site. Cites sparingly, circulates its own authority. |
| ~0.5 : 1 | Acceptable for research-heavy content with footnotes. |
| > 1 : 1 | **Broken.** Every page sends more signal out than it keeps. |
| > 3 : 1 | The corpus is a bibliography that happens to contain prose. |

A real measurement from a 113-article Persian travel corpus:

```
external dofollow : 7,059
internal          : 1,222
ratio             : 5.8 : 1
rel=nofollow      : 0
largest domain    : fa.wikipedia.org — 4,279 (61%)
worst single page : 426 external vs 4 internal
```

Two separate failures compound here:

1. **Equity drain.** Every `dofollow` outbound link passes a share of the page's
   authority away. At ~53 outbound links per 1,000-word page — one every 19 words —
   the page is functionally a redirect.
2. **Signal.** The link graph is machine-readable. A page whose citations point 88%
   at one encyclopedia article has declared, in markup, where its content came from.
   That is a stronger derivation signal than any text-similarity measure.

### The `<sup>` trap

Projects often write a rule like *"no external links in body text except
`<sup>` citations"* and then measure compliance against it. This measures nothing:
`<sup><a href="https://…">1</a></sup>` renders as an ordinary `<a href>`. Crawlers
do not care about the wrapper. If the rule is going to exist, it has to be
"zero external `dofollow` anchors in the body", and it has to be checked on the
rendered HTML.

## §2 Footnotes, not inline links

The fix keeps every citation and removes every leak.

**Inline, in the body:**

```html
…the finest wool rug in the region.<sup class="ref"><a href="#ref-1">1</a></sup>
```

The anchor is an in-page fragment. It leaves no equity and creates no outbound edge.

**Once, at the end:**

```html
<section class="footnotes">
  <h2>References</h2>
  <ol>
    <li id="ref-1">
      <a href="https://fa.wikipedia.org/wiki/…"
         rel="nofollow ugc noopener noreferrer external"
         target="_blank">Persian Wikipedia</a>
    </li>
  </ol>
</section>
```

Rules the transform must satisfy:

- **Deduplicate by URL.** One source cited 40 times is *one* footnote, not 40.
  This alone typically cuts outbound link count by 85–90%.
- **`rel="nofollow ugc noopener noreferrer"`** on every outbound anchor.
- **Idempotent.** Running the transform twice must not double-number anything.
- **Render-time, not destructive.** Never rewrite the stored post content. Cache
  the transformed HTML keyed on a hash of the source so the regex runs once.
- **Do not collide with an existing bibliography section.** If the theme already
  prints `<h2>Sources</h2>` from metadata, title the generated block
  *Footnotes* instead — two identical H2s on one page is its own problem.

Measured effect of exactly this transform on the corpus above:

```
outbound dofollow in body : 7,059 → 0
outbound links per page   : 62.5 → 7.8  (all nofollow)
reduction                 : 87.5 %
```

### When an outbound `dofollow` link is correct

Rarely, and deliberately: linking to a primary research source you are building on,
a standards document, a data provider you want to credit. Budget: **0–2 per page**,
chosen by a human. Never generated by a template.

## §3 The entity graph

Internal links should be *generated from relations*, not typed by an author.

```
Region   → its districts, its top attractions, its foods, its routes
District → its region, its attractions, 3–6 sibling districts
Leaf     → its district, its region, 3 nearby leaves, 1 food, 1 souvenir
Route    → every stop, in order, plus the region
```

Targets that hold up in practice:

| Page type | Internal links out | Internal links in |
|---|---|---|
| Region hub | 15 – 40 | from every child + home |
| District hub | 8 – 20 | from region + siblings |
| Leaf | 6 – 12 | from district + 3 siblings |

Two rules that matter more than the numbers:

1. **Never link to an unpublished slug.** Every such link is a 404 served to a
   crawler. Filter the link source by post status at query time. If the corpus is
   already published with dead links baked into the HTML, strip the `href` at
   render time — keep the `<a>` element (so SVG and layout do not break), drop the
   `href`, `target`, and `rel`. An `<a>` without `href` is valid, non-navigable
   HTML and is not followed.
2. **Rotating "related" bars are weak.** Ten generic sibling links at the bottom of
   every page is a link wheel; crawlers discount it. Contextual links inside the
   prose, plus a small, *reason-labelled* related block ("closest to this one",
   "same valley, 20 km"), carry far more.

## §4 The home page is the loudest signal

The front page is crawled more than anything else and is used to calibrate how
seriously to treat the rest of the domain.

- Every link on it must resolve to a published page. A hard-coded list of 31
  regions where 27 are unpublished means 27 (or 54, if the list renders twice)
  404s on the single most important URL.
- Build such lists from `WP_Query`/equivalent with `post_status = publish`, never
  from a static array in the template.
- Render unpublished items as non-links with a visible "coming soon" state, so the
  design survives and the crawler sees nothing.
- Counters ("448+ districts") must come from the real published count. A stat
  block that contradicts the site's own archive is a trust defect a quality rater
  will notice in seconds.

## §5 Measuring it

```bash
node skills/geo-content-strategy/scripts/geo_content_audit.mjs --dir <corpus> --site example.com
```

Relevant findings: `link-economy`, `outbound-flood`, `no-nofollow`,
`single-source`, `dead-internal`, `low-internal`.

For a live site, additionally: crawl the home page and every hub, and assert that
every `href` returns 200. A single unresolved link on a hub is worth more attention
than a hundred on leaf pages.
