# متن روی تصویر — به‌خصوص فارسی

## قاعده‌ی اصلی

**هرگز متن فارسی را داخل پرامپت تصویرسازی نگذار.**

مدل‌های تولید تصویر خط فارسی/عربی را به‌درستی نمی‌سازند:
- حروف به هم نمی‌چسبند یا اشتباه می‌چسبند
- نقطه‌ها جابه‌جا می‌شوند
- نیم‌فاصله (ZWNJ) اصلاً مفهوم ندارد
- جهت راست‌به‌چپ رعایت نمی‌شود
- خروجی معمولاً شبیه «فارسی» است اما هیچ کلمه‌ی واقعی نیست

متن انگلیسی در مدل‌های جدید بهتر شده، اما حتی آنجا هم برای متنِ مهم (برند، قیمت، CTA) روی مدل حساب نکن.

---

## راه‌حل: لایه‌ی متن واقعی

تصویر را **بدون متن** تولید کن، بعد متن را به‌عنوان یک لایه‌ی واقعی اضافه کن.

### روش ۱ — کارت HTML/CSS (توصیه‌شده)

یک فایل HTML بساز و با ابزار اسکرین‌شات (Playwright، Puppeteer، یا `wkhtmltoimage`) رندر کن:

```html
<!DOCTYPE html>
<html dir="rtl" lang="fa">
<head>
<meta charset="utf-8">
<style>
  @font-face {
    font-family: 'Vazirmatn';
    src: url('./Vazirmatn-Bold.woff2') format('woff2');
    font-weight: 700;
    font-display: block;
  }
  * { margin: 0; box-sizing: border-box; }
  body {
    width: 1200px; height: 630px;
    font-family: 'Vazirmatn', system-ui, sans-serif;
    position: relative; overflow: hidden;
  }
  .bg { position: absolute; inset: 0; width: 100%; height: 100%; object-fit: cover; }
  .scrim {
    position: absolute; inset: 0;
    background: linear-gradient(270deg, rgba(10,12,16,.88) 0%, rgba(10,12,16,.55) 55%, transparent 100%);
  }
  .content {
    position: absolute; inset: 0;
    display: flex; flex-direction: column; justify-content: center;
    padding: 72px 80px;           /* safe area */
    max-width: 62%;
  }
  h1 {
    font-size: 64px; line-height: 1.35; font-weight: 700;
    color: #fff; letter-spacing: 0;   /* هرگز letter-spacing روی فارسی */
  }
  .kicker {
    font-size: 24px; color: #ffb347; margin-bottom: 20px; font-weight: 700;
  }
</style>
</head>
<body>
  <img class="bg" src="./generated.webp" alt="">
  <div class="scrim"></div>
  <div class="content">
    <div class="kicker">کارایی وردپرس</div>
    <h1>چرا کش برای کاربران لاگین‌شده کار نمی‌کند</h1>
  </div>
</body>
</html>
```

رندر:

```bash
npx playwright screenshot --viewport-size=1200,630 card.html og-card.png
```

### روش ۲ — SVG + overlay با ImageMagick

اگر مرورگر در دسترس نیست، متن را در SVG بساز و composite کن. توجه: باید فونت فارسی روی سیستم نصب باشد و رندر shaping درست انجام شود — این روش شکننده‌تر است.

---

## فونت‌های فارسی مناسب

| فونت | مجوز | کِی |
|---|---|---|
| **Vazirmatn** | SIL OFL | پیش‌فرض امن، وزن‌های کامل، ارقام فارسی و لاتین |
| **Estedad** | SIL OFL | مدرن‌تر، برای تیتر خوب |
| **Sahel** | SIL OFL | متن، خوانا |
| **Shabnam** | SIL OFL | متن نرم‌تر |
| **IRANSans** | تجاری | فقط با لایسنس |
| **IRANYekan** | تجاری | فقط با لایسنس |

فونت را **محلی** لود کن (`@font-face` با فایل woff2 کنار فایل)، نه از CDN — چون هنگام اسکرین‌شات ممکن است نرسد و فونت جایگزین رندر شود.

## قواعد تایپوگرافی فارسی روی تصویر

```
[ ] letter-spacing هرگز روی فارسی (حروف از هم جدا می‌شوند)
[ ] line-height حداقل 1.3، ترجیحاً 1.4 (فارسی کشیدگی عمودی دارد)
[ ] dir="rtl" روی ظرف متن
[ ] text-align: right (یا start)
[ ] نیم‌فاصله در سورس HTML باشد (&zwnj; یا کاراکتر واقعی)
[ ] font-weight بالای 600 برای تیتر روی تصویر
[ ] حداکثر ۹ کلمه در تیتر کارت اجتماعی
[ ] عدد فارسی در متن روان، عدد لاتین در نسخه و کد
```

## ناحیه‌ی امن (Safe Area)

هر پلتفرم تصویر را جور دیگری می‌برد.

| هدف | ابعاد | ناحیه‌ی امن |
|---|---|---|
| OG / فیسبوک / لینکدین | 1200×630 | ۸٪ حاشیه از هر طرف |
| Twitter/X summary_large_image | 1200×628 | همان |
| تلگرام (link preview) | 1200×630 | مرکز؛ کناره‌ها ممکن است بریده شود |
| واتس‌اپ | حداقل 300×200، ترجیحاً 1200×630، زیر ۶۰۰KB | مرکز |
| تصویر شاخص وردپرس | 1600×900 | بسته به قالب، ۱۵٪ پایین ممکن است زیر متن برود |
| اینستاگرام (پست) | 1080×1350 | ۱۰٪ حاشیه |

**قاعده:** متن حیاتی را در ۶۰٪ مرکزی قاب نگه دار.

## کنتراست

- متن روی تصویر همیشه به **scrim** نیاز دارد: گرادیان تیره پشت متن.
- نسبت کنتراست حداقل **۴.۵:۱**؛ برای تیتر درشت ۳:۱ قابل قبول است اما ۴.۵ امن‌تر.
- تست: تصویر را سیاه‌وسفید کن. اگر متن گم شد، scrim را تیره‌تر کن.

```css
/* scrim ایمن برای RTL: تیرگی از راست */
background: linear-gradient(270deg, rgba(0,0,0,.85), rgba(0,0,0,.4) 60%, transparent);
```

## متن انگلیسی داخل مدل

اگر واقعاً متن لاتین کوتاه داخل تصویر می‌خواهی:

- حداکثر ۳ کلمه
- در گیومه در پرامپت: `a sign reading "CLOSED"`
- انتظار غلط املایی داشته باش؛ چند بار تولید کن
- برای هر چیز حیاتی (نام برند، قیمت) از این روش استفاده نکن
