## شروع سریع — ۳ دقیقه

**افزونه‌ی mu-plugin منتفی شد.** همه‌ی اصلاح‌ها رفت داخل قالب فرزند ۲.۴.۰ —
امن‌تر (نصب از پیشخوان، نه File Manager) و برگشت‌پذیر (پوسته‌ی قبلی را فعال کنید).

```
۱. دانلود: audits/sarzaminaryan/downloads/sarzaminaryan-child-v2.4.0.zip
۲. پیشخوان → نمایش → پوسته‌ها → افزودن → بارگذاری پوسته → نصب
۳. «جایگزینی نسخه‌ی فعلی با بارگذاری‌شده»
۴. پیشخوان → استان‌ها → انتخاب همه → ویرایش گروهی → منتشرشده
```

## دو فایل XML

آن دو فایل روی گیت‌هاب نیستند — هیچ‌کدام از ۱۱ مخزن حساب `sarzaminaryan-arch` فایل
`*.xml` خروجی وردپرس ندارد و `Cc` هم فقط یک کامیت دارد. برای این ممیزی چیزی از دست
نرفت، چون `wp-content/plugins/sa-*-importer-*/data/*.json` دقیقاً همان HTML واردشده
به وردپرس است و سایت زنده هم بررسی شد. اگر باز هم خواستید بفرستید، پوش کنید و بگویید.
