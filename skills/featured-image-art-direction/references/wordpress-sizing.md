# ابعاد، فرمت و انتشار در وردپرس

## 1) مجموعه‌ی استاندارد

| کاربرد | ابعاد | نسبت | بودجه‌ی حجم |
|---|---|---|---|
| منبع اصلی (master) | 2400×1350 | 16:9 | — (آرشیو) |
| تصویر شاخص | 1600×900 | 16:9 | ≤ 150 KB |
| کارت OG/اجتماعی | 1200×630 | 1.91:1 | ≤ 120 KB |
| داخل مقاله | 1200×675 | 16:9 | ≤ 110 KB |
| بندانگشتی آرشیو | 600×400 | 3:2 | ≤ 40 KB |
| آواتار/آیکون | 300×300 | 1:1 | ≤ 20 KB |

اگر تصویر شاخص شما LCP صفحه است (اغلب همین‌طور است)، بودجه را به **۱۰۰ کیلوبایت** سخت‌گیرانه کن.

## 2) فرمت

| فرمت | کِی | نکته |
|---|---|---|
| **AVIF** | اول انتخاب | ۳۰–۵۰٪ کوچک‌تر از WebP؛ وردپرس ۶.۵+ پشتیبانی می‌کند |
| **WebP** | پیش‌فرض امن | کیفیت ۸۰–۸۵ برای عکس، ۹۰ برای گرافیک |
| JPEG | فقط fallback | کیفیت ۸۲، progressive |
| PNG | فقط شفافیت یا گرافیک تخت | برای عکس هرگز |
| SVG | آیکون و دیاگرام | در وردپرس آپلود SVG بدون sanitize امن نیست |

```bash
# تبدیل و تغییر اندازه
cwebp -q 82 -resize 1600 0 master.png -o featured.webp
avifenc --min 24 --max 34 master.png featured.avif

# بررسی حجم
ls -lh featured.webp
```

## 3) نام‌گذاری فایل

```
✅ cache-logged-in-users-barrier.webp
✅ wp-autoload-bloat-suitcase-1600x900.webp
❌ تصویر-شاخص.webp        (نام فارسی: در URL به %D8.. تبدیل و در بعضی هاست‌ها خراب می‌شود)
❌ IMG_20260930_final2.png
❌ image1.jpg
```

قاعده: لاتین، حروف کوچک، خط تیره، توصیفی، بدون تاریخ و بدون «final».

## 4) متن جایگزین (alt)

| قاعده | مقدار |
|---|---|
| طول | زیر ۱۲۵ نویسه |
| محتوا | آنچه دیده می‌شود + چرا مهم است |
| ممنوع | «تصویر …»، «عکسی از …»، انبار کلیدواژه |
| تزئینی | `alt=""` خالی (نه حذف صفت) |
| زبان | همان زبان محتوا (فارسی) |

❌ `alt="سئو وردپرس بهینه سازی سرعت سایت افزونه کش"`
✅ `alt="سد بتنی با یک شکاف باریک که آب از آن عبور می‌کند"`
✅ توضیحی‌تر اگر تصویر اطلاعات دارد: `alt="نمودار ستونی: زمان بارگذاری قبل ۴.۲ ثانیه، بعد ۱.۱ ثانیه"`

## 5) کارایی — نکات وردپرسی

```php
// در قالب: تصویر شاخص بالای صفحه نباید lazy شود
the_post_thumbnail( 'full', array(
    'loading'       => 'eager',
    'fetchpriority' => 'high',
    'decoding'      => 'async',
) );
```

- وردپرس از ۵.۵ به بعد خودکار `loading="lazy"` می‌گذارد. برای LCP این **بد** است — روی تصویر شاخص بالای فولد آن را `eager` کن.
- `fetchpriority="high"` فقط روی **یک** تصویر در صفحه.
- `srcset` و `sizes` را حذف نکن؛ وردپرس خودش تولید می‌کند و روی موبایل فارسی حجم زیادی صرفه‌جویی می‌شود.
- اندازه‌های اضافی را غیرفعال کن تا فضای هاست و زمان آپلود هدر نرود:

```php
add_filter( 'intermediate_image_sizes_advanced', function ( $sizes ) {
    unset( $sizes['medium_large'], $sizes['1536x1536'], $sizes['2048x2048'] );
    return $sizes;
} );
```

- ابعاد `width`/`height` همیشه روی تگ باشد تا CLS نگیری.

## 6) متادیتای اجتماعی

```html
<meta property="og:image" content="https://example.ir/wp-content/uploads/2026/09/card-1200x630.webp">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="سد بتنی با یک شکاف باریک">
<meta name="twitter:card" content="summary_large_image">
```

- تلگرام و واتس‌اپ گاهی WebP را در پیش‌نمایش نشان نمی‌دهند → برای `og:image` یک **JPEG** هم بگذار اگر مخاطب ایرانی است.
- پیش‌نمایش را بعد از انتشار تست کن؛ کش پلتفرم‌ها سمج است.
- جزئیات اسکیما و متادیتا در `wp-persian-seo`.

## 7) افشای تولید با هوش مصنوعی

اگر سیاست نشریه الزام می‌کند:
- در caption: «تصویر: تولیدشده با هوش مصنوعی»
- یا در فیلد Description رسانه در کتابخانه‌ی وردپرس
- در برخی حوزه‌ها (خبری، پزشکی) این الزام قانونی/اخلاقی است، نه اختیاری.

## 8) چک‌لیست انتشار

```
[ ] ۴ برش تولید شد (شاخص، OG، داخل مقاله، بندانگشتی)
[ ] فرمت WebP/AVIF و هر فایل زیر بودجه
[ ] نام فایل لاتین و توصیفی
[ ] alt نوشته شده و کلیدواژه‌انبار نیست
[ ] تصویر شاخص eager + fetchpriority=high
[ ] width/height روی تگ هست
[ ] og:image با ابعاد و alt ست شده
[ ] پیش‌نمایش در تلگرام/واتس‌اپ تست شد
[ ] در ۱۵۰ پیکسل هم قابل تشخیص است
```
