# تایپوگرافی و فاصله‌گذاری فارسی

فونت فارسی با لاتین متفاوت رندر می‌شود. مقیاس تایپ انگلیسی را مستقیم استفاده نکن.

---

## 1) مقیاس اندازه

فارسی در اندازه‌ی کوچک زودتر از لاتین ناخوانا می‌شود (ارتفاع x کمتر، نقطه‌های زیاد).

| نقش | دسکتاپ | موبایل | نکته |
|---|---|---|---|
| تیتر hero | 48–64px | 28–36px | حداکثر ۳ خط روی ۳۶۰px |
| H2 بخش | 32–40px | 24–28px | |
| H3 | 24–28px | 20–22px | |
| متن اصلی | **18px** | **17px** | ۱۶ حداقل مطلق؛ فارسی به ۱۷–۱۸ نیاز دارد |
| متن ثانویه | 16px | 15px | |
| ریزمتن | 14px | 14px | زیر ۱۴ نرو |
| دکمه | 16–18px | 16px | |

```css
:root {
  --fs-hero:  clamp(1.75rem, 5vw, 4rem);
  --fs-h2:    clamp(1.5rem, 3.5vw, 2.5rem);
  --fs-h3:    clamp(1.25rem, 2.5vw, 1.75rem);
  --fs-body:  clamp(1.0625rem, 1.2vw, 1.125rem);  /* 17 → 18 */
  --fs-small: 0.9375rem;
}
```

در `theme.json` قالب بلوکی:
```json
{
  "settings": {
    "typography": {
      "fluid": true,
      "fontSizes": [
        { "slug": "small",  "size": "0.9375rem", "name": "کوچک" },
        { "slug": "medium", "size": "1.0625rem", "name": "متن",
          "fluid": { "min": "1.0625rem", "max": "1.125rem" } },
        { "slug": "large",  "size": "1.5rem",    "name": "بزرگ" },
        { "slug": "x-large","size": "2.5rem",    "name": "تیتر",
          "fluid": { "min": "1.75rem", "max": "4rem" } }
      ]
    }
  }
}
```

## 2) ارتفاع خط — مهم‌ترین تنظیم

فارسی کشیدگی عمودی بیشتری دارد (نقطه‌ها بالا و پایین). `line-height` انگلیسی روی فارسی فشرده به‌نظر می‌رسد.

| نقش | لاتین معمول | **فارسی** |
|---|---|---|
| تیتر بزرگ | 1.1 | **1.3–1.4** |
| تیتر متوسط | 1.2 | **1.4** |
| متن اصلی | 1.5 | **1.8–2.0** |
| متن فشرده (کارت) | 1.4 | **1.6** |
| دکمه | 1 | **1.5** |

```css
body { line-height: 1.9; }
h1, h2, h3 { line-height: 1.4; }
.button { line-height: 1.5; }
```

**این تنها تنظیمی است که بیشترین تفاوت بصری را می‌سازد.** متن فارسی با `line-height: 1.5` همیشه شلوغ به‌نظر می‌رسد.

## 3) فاصله‌ی حروف — ممنوع

```css
/* ❌ هرگز روی فارسی */
h1 { letter-spacing: 2px; }   /* حروف از هم جدا می‌شوند: س ل ا م */

/* ✅ */
h1 { letter-spacing: 0; }
```

اگر قالب یا کتابخانه‌ی CSS خارجی `letter-spacing` می‌گذارد، صفرش کن:

```css
[lang="fa"] *, [dir="rtl"] * {
  letter-spacing: 0 !important;
}
```

فاصله‌ی کلمات (`word-spacing`) هم دست نزن — فارسی خودش فاصله‌های طبیعی دارد.

## 4) طول خط

| نوع | طول امن |
|---|---|
| متن اصلی | ۶۰–۸۰ نویسه (حدود ۶۵۰–۷۵۰ پیکسل) |
| تیتر | ۴۰–۵۰ نویسه |
| متن در کارت | ۴۵–۶۰ نویسه |

```css
.content { max-width: 70ch; }
.hero h1 { max-width: 18ch; }
```

⚠️ واحد `ch` بر اساس عرض «۰» است و در فونت فارسی تقریبی است. با چشم تأیید کن.

---

## 5) وزن فونت

- متن اصلی: ۴۰۰
- تیتر: ۷۰۰
- **از وزن ۳۰۰ و کمتر استفاده نکن** — فارسی نازک روی صفحه‌های معمولی محو می‌شود، مخصوصاً روی پس‌زمینه‌ی تیره.
- حداکثر دو وزن در کل سایت (دلیل سرعتی: `wp-persian-speed/references/persian-fonts.md`).

## 6) اعداد

```css
/* اگر می‌خواهی اعداد فارسی نمایش داده شوند و فونت پشتیبانی می‌کند */
.numbers-fa { font-feature-settings: "ss01"; }  /* بسته به فونت */
```

بهتر: اعداد فارسی را مستقیم در متن بنویس (`۱۲۳`)، و در کد/نسخه لاتین.

برای جدول اعداد، از ارقام tabular استفاده کن تا ستون‌ها هم‌تراز شوند:
```css
.price, table td { font-variant-numeric: tabular-nums; }
```

## 7) مقیاس فاصله

از یک مقیاس ثابت استفاده کن، نه اعداد دلخواه.

```css
:root {
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 16px;
  --space-4: 24px;
  --space-5: 32px;
  --space-6: 48px;
  --space-7: 64px;
  --space-8: 96px;
  --space-9: 128px;
}
```

در `theme.json`:
```json
{
  "settings": {
    "spacing": {
      "spacingScale": { "steps": 0 },
      "spacingSizes": [
        { "slug": "20", "size": "clamp(1rem, 2vw, 1.5rem)",  "name": "کوچک" },
        { "slug": "40", "size": "clamp(1.5rem, 3vw, 2rem)",  "name": "متوسط" },
        { "slug": "60", "size": "clamp(2rem, 5vw, 4rem)",    "name": "بزرگ" },
        { "slug": "80", "size": "clamp(4rem, 8vw, 8rem)",    "name": "بخش" }
      ]
    }
  }
}
```

## 8) فاصله‌ی داخلی متن

| جا | فاصله |
|---|---|
| بین بندها | ۱em (با `margin-block-end`) |
| بعد از تیتر | ۰.۵em |
| قبل از تیتر | ۱.۵em |
| بین آیتم‌های فهرست | ۰.۵em |
| تورفتگی فهرست (RTL) | `padding-inline-start: 1.5em` |

```css
p + p { margin-block-start: 1em; }
h2 { margin-block: 1.5em 0.5em; }
ul, ol { padding-inline-start: 1.5em; }
li + li { margin-block-start: 0.5em; }
```

## 9) متن روی تصویر

```css
.hero-overlay {
  background: linear-gradient(270deg,
    rgba(10,12,16,.85) 0%,
    rgba(10,12,16,.55) 55%,
    transparent 100%);  /* تیرگی از راست، جهت خوانش RTL */
}
.hero-overlay h1 {
  color: #fff;
  text-shadow: 0 2px 12px rgba(0,0,0,.35);
  font-weight: 700;
}
```

- کنتراست حداقل ۴.۵:۱ حتی برای تیتر بزرگ.
- تست: تصویر را سیاه‌وسفید کن؛ اگر متن گم شد، scrim را تیره‌تر کن.
- جزئیات بیشتر در `featured-image-art-direction/references/text-in-image.md`.
