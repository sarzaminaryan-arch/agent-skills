# ترکیب‌بندی راست‌به‌چپ

**قاعده‌ی اصلی:** چیدمان RTL را از اول طراحی کن. آینه‌کردن یک طرح LTR در پایان کار، همیشه دیده می‌شود.

---

## 1) مسیر نگاه

در فارسی، چشم از **بالا-راست** شروع می‌کند و در قطر به سمت **پایین-چپ** می‌رود. الگوی Z معکوس می‌شود.

```
LTR:                          RTL:
┌─────────────────┐          ┌─────────────────┐
│ ①──────────②   │          │   ②──────────① │
│      ╱          │          │          ╲      │
│     ╱           │          │           ╲     │
│ ③──────────④   │          │   ④──────────③ │
└─────────────────┘          └─────────────────┘
```

پیامدها:
- **لوگو سمت راست** بالا
- **تیتر اصلی راست‌چین**
- **CTA اصلی سمت راست** یا وسط، نه گوشه‌ی چپ
- در بخش دوستونی، **متن راست و تصویر چپ** خوانش طبیعی‌تری دارد
- آیتم مهم‌تر در گرید، سمت راست

---

## 2) هدر

```
┌──────────────────────────────────────────────┐
│  [ورود] [جستجو]      منو منو منو      لوگو  │
└──────────────────────────────────────────────┘
       چپ ←                          → راست
```

- لوگو راست، منو وسط یا چسبیده به لوگو، اقدام‌های فرعی چپ
- CTA هدر می‌تواند چپ باشد (جای «آخر مسیر» چشم) — این درست است، نه اشتباه
- هدر چسبان (sticky) روی موبایل ارتفاع کم بگیرد، حداکثر ۶۰ پیکسل

---

## 3) بخش قهرمان (Hero)

سه الگوی امن:

### الف) راست‌چین با تصویر چپ
```
┌───────────────────────────────────┐
│  [تصویر]          تیتر بزرگ      │
│                   زیرتیتر         │
│                   [دکمه]          │
└───────────────────────────────────┘
```
طبیعی‌ترین برای فارسی. تصویر سمت چپ، فضای منفی سمت راست برای تیتر.

### ب) وسط‌چین
```
┌───────────────────────────────────┐
│           تیتر بزرگ               │
│           زیرتیتر                 │
│           [دکمه]                  │
└───────────────────────────────────┘
```
امن، بی‌ریسک، اما کم‌شخصیت. برای صفحات ساده خوب است.

### ج) تصویر تمام‌عرض با متن روی آن
متن سمت راست، scrim گرادیانی از راست. جزئیات در `featured-image-art-direction/references/text-in-image.md`.

**هرگز:** تیتر فارسی چپ‌چین روی تصویر. غلط به‌نظر می‌رسد حتی اگر نتوانی بگویی چرا.

## 4) CSS منطقی

از اول با logical properties بنویس تا هیچ فایل RTL جدا لازم نباشد.

```css
.card {
  padding-inline: 24px;
  padding-block: 32px;
  margin-inline-start: 0;
  margin-inline-end: auto;
  border-inline-start: 3px solid var(--accent);
  text-align: start;
}

.hero {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 48px;
}

/* آیکون جهت‌دار */
[dir="rtl"] .icon-arrow {
  transform: scaleX(-1);
}
```

جدول تبدیل کامل در `wp-persian-debug/references/rtl-layout-debug.md` §3.

در `theme.json` قالب بلوکی، از `spacing` presets استفاده کن — مقادیر منطقی‌اند و خودکار درست می‌چرخند.

## 5) گرید و تقارن

- تقارن کامل، صفحه را بی‌روح می‌کند. عدم تقارن عمدی بساز: ستون ۷/۵ به‌جای ۶/۶.
- در RTL، ستون پهن‌تر را سمت راست بگذار (جایی که چشم اول می‌رود).
- فضای منفی در سمت راست، تیتر را قدرتمندتر نشان می‌دهد.
- گرید ۱۲ ستونی استاندارد کار می‌کند؛ فقط جهت شماره‌گذاری معکوس است.

```css
.section {
  display: grid;
  grid-template-columns: 7fr 5fr;   /* ستون پهن‌تر اول = سمت راست در RTL */
  gap: clamp(24px, 4vw, 64px);
}

@media (max-width: 782px) {
  .section { grid-template-columns: 1fr; }
}
```

## 6) موبایل — اولویت اول

بیش از ۸۰٪ ترافیک فارسی موبایلی است. ۳۶۰ پیکسل را اول طراحی کن.

```
[ ] هدر حداکثر ۶۰ پیکسل ارتفاع
[ ] منوی همبرگری از سمت راست باز شود (نه چپ)
[ ] دکمه‌ی منو سمت چپ یا راست — یکدست با بقیه‌ی سایت
[ ] هدف لمسی حداقل ۴۴×۴۴ پیکسل
[ ] فاصله بین دکمه‌ها حداقل ۸ پیکسل
[ ] تیتر hero حداکثر ۳ خط روی ۳۶۰px
[ ] بدون اسکرول افقی
[ ] CTA اصلی بدون اسکرول دیده شود
[ ] فرم‌ها تک‌ستونی
[ ] جدول‌ها overflow-x: auto داشته باشند
```

تست اسکرول افقی در `wp-persian-debug/references/rtl-layout-debug.md` §4.

## 7) ریتم عمودی

فاصله بین بخش‌ها روایت را می‌سازد.

| نقش | فاصله‌ی عمودی (دسکتاپ) | موبایل |
|---|---|---|
| بین بخش‌های اصلی | ۹۶–۱۲۸px | ۶۴px |
| بین عنوان بخش و محتوا | ۳۲–۴۸px | ۲۴px |
| بین کارت‌ها در گرید | ۲۴–۳۲px | ۱۶px |
| داخل کارت | ۱۶–۲۴px | ۱۶px |

```css
:root {
  --space-section: clamp(64px, 8vw, 128px);
  --space-block: clamp(24px, 4vw, 48px);
}
.section { padding-block: var(--space-section); }
```

**تکنیک:** فاصله را بین بخش‌ها متغیر کن. دو بخش مرتبط را نزدیک‌تر و بخش جدید را دورتر بگذار — این گروه‌بندی بصری می‌سازد.

## 8) رنگ و کنتراست

- پس‌زمینه‌ی متناوب (سفید / خاکستری روشن) مرز بخش‌ها را مشخص می‌کند بدون خط کشیدن.
- رنگ تأکید فقط برای CTA اصلی. اگر همه‌جا استفاده شود، دیگر تأکید نیست.
- کنتراست متن حداقل ۴.۵:۱ — فونت فارسی معمولاً نازک‌تر رندر می‌شود، پس سخت‌گیرتر باش.
- متن خاکستری روشن روی سفید در فارسی خیلی زودتر از انگلیسی ناخوانا می‌شود.

```css
/* حداقل امن برای متن فارسی */
--text-primary: #1a1a1a;    /* نه #333 */
--text-secondary: #555;     /* نه #888 */
```

## 9) عناصر جهت‌دار

| عنصر | در RTL |
|---|---|
| فلش «ادامه» | به سمت **چپ** |
| فلش «بازگشت» | به سمت **راست** |
| نوار پیشرفت | از راست پر می‌شود |
| اسلایدر / کروسل | حرکت از راست به چپ |
| Breadcrumb | خانه در راست‌ترین جایگاه |
| آیکون‌های غیرجهت‌دار (سبد، جستجو، کاربر) | تغییر نمی‌کنند |
| نمودار زمانی | زمان از راست به چپ پیش می‌رود |
| شماره‌گذاری مراحل | ۱ در راست |

```css
[dir="rtl"] .arrow-next  { transform: scaleX(-1); }
[dir="rtl"] .progress    { transform: scaleX(-1); }
[dir="rtl"] .progress > * { transform: scaleX(-1); }  /* محتوای داخلی را برگردان */
```

## 10) چک‌لیست ترکیب‌بندی

```
[ ] طرح از ابتدا RTL طراحی شده، نه آینه‌شده
[ ] لوگو سمت راست
[ ] تیتر اصلی راست‌چین یا وسط‌چین
[ ] CSS با logical properties نوشته شده
[ ] عدم تقارن عمدی وجود دارد
[ ] ۳۶۰ پیکسل اول طراحی شده
[ ] بدون اسکرول افقی در هیچ بریک‌پوینتی
[ ] فلش‌ها و عناصر جهت‌دار برگردانده شده‌اند
[ ] ریتم عمودی متغیر است، نه یکنواخت
[ ] کنتراست متن ≥ 4.5:1
[ ] رنگ تأکید فقط روی CTA اصلی
```
