# استراتژی صفحه‌ی اول

---

## 1) سه گزینه‌ی وردپرس

| گزینه | تنظیم | کِی |
|---|---|---|
| **آخرین نوشته‌ها** | `Settings → Reading → Your latest posts` | بلاگ خالص، سایت خبری با انتشار روزانه |
| **برگه‌ی ثابت** | `Settings → Reading → A static page` | کسب‌وکار، فروشگاه، محصول، نمونه‌کار |
| **تمپلیت front-page** | `templates/front-page.html` در قالب بلوکی | وقتی صفحه‌ی اول ساختار خاص و کدمحور دارد |

```bash
wp option get show_on_front       # posts | page
wp option get page_on_front
wp option get page_for_posts
```

تنظیم برگه‌ی ثابت:
```bash
wp option update show_on_front page
wp option update page_on_front 12
wp option update page_for_posts 15    # برگه‌ی «بلاگ»
```

## 2) سلسله‌مراتب اولویت وردپرس

وردپرس به این ترتیب دنبال تمپلیت می‌گردد:

```
front-page.php / front-page.html     ← همیشه برنده، چه «نوشته‌ها» چه «برگه‌ی ثابت»
  ↓ (اگر نبود)
home.php / home.html                 ← وقتی نمایش «آخرین نوشته‌ها» است
  ↓
page.php / page.html                 ← وقتی برگه‌ی ثابت است
  ↓
index.php / index.html
```

**نکته‌ی مهم:** اگر `front-page.html` وجود داشته باشد، تنظیم `Settings → Reading` نادیده گرفته می‌شود. این علت رایج «تغییراتم اعمال نمی‌شود» است.

## 3) انتخاب بر اساس نوع سایت

### بلاگ / مجله
- «آخرین نوشته‌ها» یا `home.html` سفارشی
- بالای صفحه: ۱–۳ مطلب شاخص، بعد فهرست
- اگر بیش از ۵۰ مطلب داری، دسته‌بندی‌ها را در صفحه‌ی اول نشان بده
- صفحه‌بندی مهم است — بی‌نهایت اسکرول برای سئو بد است

### کسب‌وکار خدماتی
- برگه‌ی ثابت
- ساختار: قلاب → مشکل → راه‌حل → اثبات → CTA
- بلاگ در `/blog/`

### فروشگاه
- برگه‌ی ثابت با محصولات شاخص
- دسته‌بندی‌های اصلی باید در صفحه‌ی اول دیده شوند
- نماد اعتماد الکترونیکی (اینماد) و راه‌های پرداخت، بالای فولد یا نزدیک آن
- جستجو در هدر، نه مخفی

### نمونه‌کار
- برگه‌ی ثابت با گرید کارها
- کمترین متن، بیشترین تصویر
- تماس همیشه در دسترس

### محصول / SaaS
- برگه‌ی ثابت
- قلاب → دمو بصری → قابلیت‌ها بر اساس سود → قیمت → CTA

## 4) تست پنج‌ثانیه‌ای

قبل از طراحی، بعد از طراحی، و قبل از انتشار.

به کسی که سایت را نمی‌شناسد پنج ثانیه صفحه را نشان بده، ببند، بپرس:

```
۱. این سایت چه می‌کند؟
۲. برای چه کسی است؟
۳. حالا باید چه کار کنم؟
```

اگر هر سه را نتوانست بگوید، هدر مشکل دارد — نه بقیه‌ی صفحه.

## 5) یک اقدام اصلی

هر صفحه‌ی اول دقیقاً **یک** اقدام اصلی دارد. بقیه ثانویه‌اند و باید بصری کوچک‌تر باشند.

| نوع سایت | اقدام اصلی | اقدام‌های ثانویه |
|---|---|---|
| خدماتی | «مشاوره رایگان بگیر» | دیدن نمونه‌کار، تماس |
| فروشگاه | «محصولات را ببین» یا خرید مستقیم | دسته‌ها، تخفیف‌ها |
| بلاگ | «عضو خبرنامه شو» یا خواندن مطلب شاخص | دسته‌ها، جستجو |
| SaaS | «رایگان شروع کن» | دیدن دمو، قیمت |
| نمونه‌کار | «پروژه‌ات را شروع کن» | دیدن کارها |

**تست:** اگر دو دکمه با یک اندازه و یک رنگ کنار هم‌اند، اقدام اصلی نداری.

## 6) طول صفحه

| نوع | تعداد بخش | طول اسکرول موبایل |
|---|---|---|
| بلاگ | ۳–۵ | کوتاه |
| خدماتی | ۶–۸ | متوسط |
| فروشگاه | ۵–۷ | متوسط |
| SaaS | ۷–۹ | بلند (فروش بیشتر توضیح می‌خواهد) |
| نمونه‌کار | ۳–۴ | کوتاه |

بیش از ۹ بخش یعنی صفحه‌ی اول شده نقشه‌ی سایت. بخش‌ها را به صفحات داخلی منتقل کن.

## 7) اشتباهات رایج در صفحه‌های اول فارسی

| اشتباه | چرا بد است |
|---|---|
| اسلایدر پنج‌تایی در هدر | LCP خراب، کاربر فقط اسلاید اول را می‌بیند |
| «به وبسایت ما خوش آمدید» | صفر اطلاعات، صفر انگیزه |
| متن «درباره ما» در صفحه‌ی اول | بازدیدکننده به خودش فکر می‌کند، نه به شما |
| شش دکمه با رنگ‌های مختلف | هیچ اقدام اصلی‌ای وجود ندارد |
| لوگوی مشتریان جعلی | ریسک اعتباری و حقوقی |
| آیکون‌های استوک بی‌ربط | نویز بصری |
| شمارنده‌ی انیمیشنی اعداد ساختگی | «+۱۰۰۰ مشتری راضی» بدون پشتوانه |
| پاپ‌آپ فوری خبرنامه | جریمه‌ی گوگل روی موبایل + خروج کاربر |
| ویدیوی خودکار با صدا | خروج فوری |
| فوتر با ۸۰ لینک | رقیق‌شدن اعتبار و بی‌فایده برای کاربر |

## 8) چک‌لیست استراتژی

```
[ ] اقدام اصلی در یک فعل نوشته شده
[ ] جمله‌ی تست پنج‌ثانیه‌ای نوشته شده
[ ] اعتراض اصلی بازدیدکننده شناسایی شده
[ ] اثبات واقعی موجود فهرست شده
[ ] گزینه‌ی صفحه‌ی اول (ثابت/نوشته‌ها/تمپلیت) انتخاب شده
[ ] تعداد بخش‌ها بین ۳ تا ۹ است
[ ] هر بخش یک هدف مشخص دارد
[ ] هیچ بخشی برای محتوایی که وجود ندارد طراحی نشده
```
