# اسکلت بخش‌ها بر اساس نوع سایت

هر اسکلت: ترتیب، هدف هر بخش، محتوای الزامی، و چیزی که باید حذف شود.

## 1) کسب‌وکار خدماتی — ۶ تا ۸ بخش

| # | بخش | هدف | محتوای الزامی |
|---|---|---|---|
| ۱ | **قهرمان** | در ۵ ثانیه بفهماند چه می‌کنی و برای که | تیتر مشخص، زیرتیتر یک‌جمله‌ای، یک CTA اصلی |
| ۲ | **مشکل** | خواننده بگوید «دقیقاً همین» | ۲–۳ درد واقعی، با زبان خود مشتری |
| ۳ | **راه‌حل / خدمات** | چه می‌دهی | ۳–۴ خدمت، هرکدام با سود نه ویژگی |
| ۴ | **چگونه کار می‌کند** | کاهش ریسک ذهنی | ۳ گام ساده |

| ۶ | **درباره‌ی ما (کوتاه)** | اعتماد انسانی | ۳ جمله + یک عکس واقعی |
| ۷ | **سؤالات متداول** | رفع آخرین اعتراض‌ها | ۴–۶ سؤال واقعی |

**حذف کن:** تاریخچه‌ی شرکت، پیام مدیرعامل، لوگوی مشتریانی که مشتری نیستند، آیکون‌های استوک بی‌ربط.

## 2) فروشگاه — ۵ تا ۷ بخش

| # | بخش | هدف | محتوای الزامی |
|---|---|---|---|
| ۱ | **قهرمان** | دسته یا کمپین اصلی | تصویر محصول واقعی + CTA خرید |
| ۲ | **دسته‌بندی‌ها** | مسیر پیدا کردن | ۴–۸ دسته با تصویر |
| ۳ | **محصولات پرفروش/جدید** | کشف | ۴–۸ محصول با قیمت واضح |
| ۴ | **چرا از ما** | رفع تردید خرید | ارسال، ضمانت، بازگشت وجه، پشتیبانی |
| ۵ | **اعتماد** | امنیت خرید | اینماد، درگاه‌های پرداخت، نظرات واقعی |
| ۶ | **کمپین/تخفیف** (اختیاری) | فوریت | فقط اگر واقعی است، با تاریخ پایان |
| ۷ | **خبرنامه** | بازگشت مشتری | یک فیلد، بدون پاپ‌آپ فوری |

**الزامی در فروشگاه ایرانی:**
- جستجو در هدر، قابل مشاهده نه مخفی
- قیمت واضح با واحد («تومان» یا «ریال» — یکی را انتخاب و همه‌جا ثابت نگه دار)
- وضعیت موجودی
- نماد اعتماد الکترونیکی در فوتر یا نزدیک CTA
- شرایط ارسال، قابل دسترس از صفحه‌ی اول

**حذف کن:** اسلایدر پنج‌تایی بنر، شمارنده‌ی معکوس دائمی، پاپ‌آپ فوری تخفیف.

## 6) آناتومی بخش قهرمان

بهترین‌سرمایه‌گذاری روی صفحه. اجزا:

```
┌─────────────────────────────────────────┐
│                                         │
│   [برچسب کوچک - اختیاری]                │
│   تیتر اصلی، حداکثر ۹ کلمه              │
│   زیرتیتر، یک جمله، توضیح مشخص          │
│                                         │
│   [CTA اصلی]  [اقدام ثانویه - متنی]    │
│                                         │
│   [نشانه‌ی اعتماد کوچک - اختیاری]       │
│                                         │
└─────────────────────────────────────────┘
```

| جزء | قاعده |
|---|---|
| برچسب | ۲–۴ کلمه، رنگ تأکید، اختیاری |
| تیتر | ≤ ۹ کلمه، مشخص، بدون صفت توخالی |
| زیرتیتر | یک جمله، ≤ ۲۰ کلمه، توضیح «چطور» یا «برای که» |
| CTA اصلی | فعل مشخص، دکمه‌ی پررنگ |
| اقدام ثانویه | لینک متنی یا دکمه‌ی outline — هرگز هم‌وزن اصلی |
| نشانه‌ی اعتماد | «بدون نیاز به کارت بانکی» / «۲۴۰۰ کاربر فعال» — فقط اگر واقعی |
| تصویر | واقعی؛ نه آیکون انتزاعی، نه استوک کلیشه‌ای |

## 7) بخش اثبات — چه چیزی واقعاً کار می‌کند

به‌ترتیب قدرت:

1. **نتیجه‌ی عددی مشتری با نام** — «فروش ماهانه‌ی X از ۲۰ به ۷۵ میلیون رسید»
2. **نمونه‌کار با قبل/بعد**
3. **نظر با نام کامل، عکس واقعی، و جزئیات مشخص**
4. **عدد واقعی کسب‌وکار** — «۳۴۰ پروژه از ۱۳۹۸»
5. **لوگوی مشتریان واقعی**
6. نظر بی‌نام و کلی — تقریباً بی‌اثر

⚠️ **هرگز نظر، عدد، لوگو، یا نام مشتری جعلی نساز.** اگر اثبات وجود ندارد، بخش اثبات را حذف کن و به‌جایش ضمانت یا نمونه‌ی رایگان بگذار.

## 8) بخش سؤالات متداول

- سؤال‌ها را از تیکت‌های واقعی پشتیبانی یا مکالمات فروش بردار.
- هر پاسخ زیر ۶۰ کلمه.
- سخت‌ترین سؤال (قیمت، محدودیت، رقیب) را بگذار — اجتناب از آن، اعتماد را کم می‌کند.
- آکاردئون با اولین آیتم باز.
- اسکیمای FAQPage اضافه کن → `wp-persian-seo/references/schema-persian.md` §4.
