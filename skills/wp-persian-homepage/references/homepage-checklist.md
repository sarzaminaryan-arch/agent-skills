# چک‌لیست نهایی صفحه‌ی اول

قبل از تحویل، همه را طی کن. اسکریپت `homepage_check.mjs` بخش «الف» و «ه» را خودکار می‌کند.

---

## الف) ساختار

```
[ ] دقیقاً یک <h1> در صفحه
[ ] h1 همان پیام اصلی است، نه نام سایت
[ ] سلسله‌مراتب تیترها بدون پرش (h1 → h2 → h3)
[ ] بین ۳ تا ۹ بخش
[ ] هر بخش یک هدف نوشته‌شده دارد
[ ] یک CTA اصلی، بصری متمایز
[ ] اقدام‌های ثانویه ضعیف‌تر از اصلی‌اند
[ ] هیچ بخشی محتوای ساختگی ندارد
```

## ب) محتوا

```
[ ] تست پنج‌ثانیه‌ای روی یک نفر ناآشنا انجام شد
[ ] تیتر hero زیر ۹ کلمه و مشخص
[ ] زیرتیتر یک جمله و مفید
[ ] متن دکمه‌ها فعل مشخص است
[ ] عنوان بخش‌ها محتوامحورند
[ ] ویژگی‌ها به سود ترجمه شده‌اند
[ ] هیچ عدد، نظر، یا لوگوی جعلی نیست
[ ] لحن در کل صفحه یکدست است
[ ] هیچ عبارت ممنوعی (persian-copywriting.md §8) نمانده
[ ] ریزمتن فرم‌ها نوشته شده
```

## ج) تایپوگرافی فارسی

```
[ ] متن اصلی حداقل ۱۷px
[ ] line-height متن ۱.۸–۲.۰، تیتر ۱.۳–۱.۴
[ ] هیچ letter-spacing روی فارسی
[ ] نیم‌فاصله‌ها سالم‌اند (می‌شود، سایت‌ها، سریع‌تر)
[ ] ی و ک فارسی، نه عربی
[ ] گیومه‌ی فارسی «» و ویرگول ،
[ ] اعداد نمایشی فارسی، اعداد فنی لاتین
[ ] حداکثر دو وزن فونت، هیچ‌کدام زیر ۴۰۰
```

## د) RTL و چیدمان

```
[ ] <html lang="fa-IR" dir="rtl">
[ ] لوگو سمت راست
[ ] تیتر اصلی راست‌چین یا وسط‌چین
[ ] CSS با logical properties
[ ] فلش‌ها و عناصر جهت‌دار برگردانده شده‌اند
[ ] بدون اسکرول افقی روی ۳۶۰px، ۷۶۸px، ۱۴۴۰px
[ ] منوی موبایل از سمت درست باز می‌شود
[ ] فرم‌ها جهت درست دارند (ایمیل و شماره LTR)
[ ] عدم تقارن عمدی وجود دارد
```

## ه) عملکرد

```
[ ] LCP زیر ۲.۵ ثانیه روی موبایل
[ ] CLS زیر ۰.۱
[ ] INP زیر ۲۰۰ms
[ ] TTFB زیر ۸۰۰ms خارج از کش
[ ] وزن کل صفحه زیر ۹۰۰ کیلوبایت
[ ] فونت‌ها زیر ۱۵۰ کیلوبایت، subset‌شده، woff2
[ ] تصویر hero: WebP/AVIF، eager، fetchpriority=high
[ ] فقط یک fetchpriority=high در صفحه
[ ] همه‌ی تصاویر width/height دارند
[ ] هیچ اسکریپت خارجی blocking در head نیست
[ ] بدون اسلایدر سنگین (یا محدود و بهینه)
```

## و) دسترس‌پذیری

```
[ ] کنتراست متن ≥ 4.5:1 همه‌جا
[ ] ناوبری کامل با کیبورد ممکن است
[ ] فوکوس قابل مشاهده روی همه‌ی عناصر تعاملی
[ ] همه‌ی تصاویر alt دارند (تزئینی‌ها alt="")
[ ] متن لینک‌ها معنادار است، نه «اینجا کلیک کنید»
[ ] هدف‌های لمسی ≥ 44×44px
[ ] لندمارک‌های semantic (header, nav, main, footer)
[ ] فرم‌ها label دارند، نه فقط placeholder
[ ] هیچ اطلاعاتی فقط با رنگ منتقل نمی‌شود
[ ] prefers-reduced-motion رعایت شده
```

## ز) سئو

```
[ ] تگ title صفحه‌ی اول ۵۰–۶۰ نویسه و توصیفی
[ ] توضیحات متا ۱۴۰–۱۶۰ نویسه
[ ] یک canonical
[ ] og:image با ابعاد ۱۲۰۰×۶۳۰ و og:image:alt
[ ] اسکیمای Organization یا LocalBusiness
[ ] اسکیمای WebSite با SearchAction (اگر جستجو دارد)
[ ] لینک به صفحات مهم داخلی
[ ] سایت‌مپ در دسترس
[ ] بدون noindex
```
جزئیات در `wp-persian-seo`.

## ح) فنی

```
[ ] همه‌ی رشته‌ها escape و ترجمه‌پذیرند
[ ] هیچ inline <style> در مارک‌آپ بلوکی نیست
[ ] رنگ و فاصله از preset‌های theme.json می‌آیند
[ ] هیچ URL هاردکد شده‌ای نیست (get_theme_file_uri استفاده شده)
[ ] بخش‌های پویا با ۰، ۱، و چند آیتم تست شده‌اند
[ ] query-no-results برای هر Query Loop
[ ] فرم‌ها nonce و اعتبارسنجی دارند
[ ] در سه مرورگر تست شده
```

## ط) تحویل

```
[ ] در حالت مهمان و لاگین‌شده تست شد
[ ] در پنجره‌ی ناشناس تست شد
[ ] پیش‌نمایش لینک در تلگرام و واتس‌اپ تست شد
[ ] کش پاک شد و دوباره تست شد
[ ] اعداد قبل/بعد عملکرد ثبت شدند
[ ] فایل perf-baseline.md به‌روز شد
```

---

## تست ۶۰ ثانیه‌ای نهایی

۱. صفحه را روی موبایل واقعی باز کن. چقدر طول کشید؟
۲. پنج ثانیه نگاه کن، ببند. چه فهمیدی؟
۳. اسکرول کن تا پایین. کجا حوصله‌ات سر رفت؟
۴. سعی کن فقط با کیبورد به دکمه‌ی اصلی برسی.
۵. زوم کن تا ۲۰۰٪. چیزی شکست؟
۶. وای‌فای را کند کن. چه چیزی اول لود می‌شود؟
