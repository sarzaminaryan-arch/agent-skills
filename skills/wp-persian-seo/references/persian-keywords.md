# کلیدواژه و نیت جستجو در فارسی

جریان کار کلیدواژه‌ی انگلیسی روی فارسی مستقیم جواب نمی‌دهد. دلایلش اینجاست.

---

## 1) واریانت‌های املایی — مسئله‌ی اصلی

یک عبارت فارسی می‌تواند به شش شکل تایپ شود و هر شش، کوئری متفاوتی هستند:

| شکل | مثال |
|---|---|
| با نیم‌فاصله | `بهینه‌سازی سایت` |
| با فاصله‌ی کامل | `بهینه سازی سایت` |
| بدون فاصله | `بهینهسازی سایت` |
| با ي عربی | `بهينه‌سازي سايت` |
| بدون «ی» پایانی | `بهینه ساز سایت` |
| با غلط املایی رایج | `بهینح سازی` |

**گوگل بیشترشان را نرمال‌سازی می‌کند، اما نه همه را** — به‌خصوص فاصله‌ی کامل در مقابل نیم‌فاصله معمولاً یکی حساب می‌شود، اما ي/ك عربی گاهی نه.

### راهبرد

1. در **محتوا** فقط شکل درست را بنویس (نیم‌فاصله، ی و ک فارسی).
2. در **عنوان و H1** شکل پرجستجوتر را بگذار — که همیشه شکل درست نیست.
3. واریانت‌ها را با کلمه‌انبار کردن پوشش نده. یک بار در متن طبیعی کافی است.
4. اگر تفاوت حجم جستجو زیاد است، یک بخش FAQ با شکل دیگر بنویس.

### بررسی آلودگی محتوا

```bash
grep -rnP '[يك]' wp-content/themes/mytheme/ | head
wp db query "SELECT ID, post_title FROM wp_posts WHERE post_title LIKE '%ي%' OR post_title LIKE '%ك%' LIMIT 20;"
```

## 2) وام‌واژه در برابر معادل فارسی

کاربر ایرانی معمولاً واژه‌ی انگلیسی یا نویسه‌گردانی‌شده را جستجو می‌کند، نه معادل فرهنگستانی.

| معادل رسمی | چیزی که واقعاً جستجو می‌شود |
|---|---|
| حافظه پنهان | کش |
| رایانامه | ایمیل |
| بارگذاری | آپلود |
| پیوند یکتا | لینک، پرمالینک |
| پایگاه داده | دیتابیس |
| میان‌افزار | پلاگین، افزونه |
| برگردان | ترجمه |
| تارنما | سایت |

**قاعده:** واژه‌ی پرجستجو را در عنوان و H1 بگذار؛ معادل فارسی را یک‌بار در متن بیاور. نه برعکس.

## 3) کوئری‌های ترکیبی فارسی/لاتین

بسیار رایج و اغلب نادیده گرفته می‌شود:

```
آموزش wordpress
افزونه seo وردپرس
نصب php 8 روی هاست
خطای 500 وردپرس
دانلود قالب woocommerce
```

**راهبرد:** در محتوا هر دو شکل را طبیعی بیاور. مثلاً یک‌بار «وردپرس (WordPress)» و بعد فقط «وردپرس». در H2ها می‌توانی شکل لاتین را بگذاری اگر کاربر همان‌طور جستجو می‌کند.

## 4) پیشوندهای نیت‌محور فارسی

| پیشوند | نیت | نوع محتوا |
|---|---|---|
| آموزش … | یادگیری | راهنمای گام‌به‌گام |
| چگونه … / چطور … | حل مسئله | how-to کوتاه و مستقیم |
| بهترین … | مقایسه/خرید | فهرست با معیار شفاف |
| قیمت … | تراکنشی | جدول قیمت واقعی |
| دانلود … | ابزار | صفحه‌ی دانلود؛ احتیاط در حوزه‌ی نال‌شده |
| خطای … / مشکل … | عیب‌یابی | علامت → علت → درمان |
| … چیست | تعریفی | تعریف کوتاه در ۲ جمله‌ی اول |
| … یا … (مقایسه) | تصمیم | جدول + توصیه‌ی صریح |

**نکته‌ی مهم:** اگر کوئری با «خطای» شروع می‌شود، کاربر راه‌حل می‌خواهد نه تاریخچه. در ۵۰ کلمه‌ی اول راه‌حل را بده.

## 5) ابزارها و محدودیت‌هایشان

| ابزار | داده‌ی فارسی | نکته |
|---|---|---|
| Google Search Console | ✅ بهترین منبع | داده‌ی واقعی سایت خودت؛ از `Performance → Queries` شروع کن |
| Google Keyword Planner | ⚠️ محدود | برای ایران ممکن است حجم را تجمیعی نشان دهد |
| Google Trends | ✅ | برای مقایسه‌ی واریانت‌های املایی عالی است |
| Ahrefs / Semrush | ⚠️ ناقص | پوشش فارسی ضعیف، اما برای رقیب‌سنجی مفید |
| پیشنهاد خودکار گوگل | ✅ رایگان | تایپ ناقص و دیدن پیشنهادها |
| «جستجوهای مرتبط» پای SERP | ✅ | منبع بسیار خوب برای کلیدواژه‌ی دم‌بلند |
| «People also ask» فارسی | ✅ | مستقیم به FAQ تبدیلش کن |
| ابزارهای ایرانی کلمه‌کلیدی | ⚠️ | داده را با GSC اعتبارسنجی کن |

**روش عملی و رایگان:** در گوگل عبارت را تایپ کن، ۱۰ نتیجه‌ی اول را باز کن، H2هایشان را بیرون بکش. آن‌ها ساختار مورد انتظار گوگل برای آن نیت‌اند.

## 6) بررسی نیت پیش از نوشتن

قبل از نوشتن، SERP فارسی همان کوئری را نگاه کن و جواب بده:

```
[ ] ده نتیجه‌ی اول چه نوع محتوایی‌اند؟ (راهنما / فهرست / محصول / ویدیو / انجمن)
[ ] طول متوسطشان چقدر است؟
[ ] فیچر اسنیپت دارد؟ از چه فرمتی؟ (بند / فهرست / جدول)
[ ] «People also ask» چه می‌پرسد؟
[ ] آیا نتیجه‌ی ویدیویی (آپارات/یوتیوب) بالا آمده؟
[ ] آیا سایت‌های بزرگ کل صفحه‌ی اول را گرفته‌اند؟ (اگر بله، کوئری دم‌بلندتر انتخاب کن)
```

اگر نوع محتوای تو با نُه نتیجه‌ی اول فرق دارد، احتمالاً نیت را اشتباه خوانده‌ای.

## 7) نگاشت کلیدواژه به صفحه

یک جدول ساده نگه دار — از cannibalization جلوگیری می‌کند:

| URL | کلیدواژه‌ی اصلی | کلیدواژه‌های فرعی | نیت |
|---|---|---|---|
| /wordpress-cache-guide/ | کش وردپرس | افزونه کش وردپرس، بهترین کش | آموزشی |
| /wordpress-speed/ | سرعت سایت وردپرس | افزایش سرعت وردپرس | آموزشی |

**قاعده:** یک کلیدواژه‌ی اصلی = یک صفحه. اگر دو صفحه یک کوئری را هدف گرفته‌اند، ادغامشان کن و ۳۰۱ بزن.

---

## 8) چگالی کلیدواژه

فراموشش کن. عدد جادویی وجود ندارد.

قاعده‌ی عملی:
- کلیدواژه‌ی اصلی: در عنوان، H1، ۱۰۰ کلمه‌ی اول، و یک H2
- بعد از آن: هر جا **طبیعی** بود
- اگر خواندن جمله سخت شد، حذفش کن

تکرار مصنوعی کلیدواژه در فارسی خیلی زودتر از انگلیسی توی ذوق می‌زند، چون ساختار جمله انعطاف کمتری دارد. `content-humanizer` را بخوان.
