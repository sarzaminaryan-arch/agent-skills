## شروع سریع — ۱۰ دقیقه

### گام ۱ — گرفتن فایل

این نشانی را در مرورگر باز کنید و با `Ctrl+S` ذخیره کنید:

```
https://raw.githubusercontent.com/sarzaminaryan-arch/agent-skills/arena/01a0ef63-agent-skills/audits/sarzaminaryan/mu-plugins/sa-content-guard.php
```

یا از صفحه‌ی گیت‌هاب: مخزن `agent-skills` → شاخه‌ی `arena/01a0ef63-agent-skills`
→ `audits/sarzaminaryan/mu-plugins/` → روی فایل کلیک → دکمه‌ی **Raw** → ذخیره.

**هنگام ذخیره حواستان به سه چیز باشد:**

| | |
|---|---|
| نام فایل | دقیقاً `sa-content-guard.php` — نه `.php.txt` و نه `(1).php` |
| کدگذاری | UTF-8 **بدون BOM**. اگر با Notepad ویندوز باز کردید، «Save as → UTF-8» (نه «UTF-8 with BOM») |
| ویرایش | هیچ. حتی یک خط خالی قبل از `<?php` باعث خطای «headers already sent» می‌شود |

بهترین راه برای پرهیز از این سه: **اصلاً دانلود نکنید.** در cPanel → File Manager
مستقیم فایل خالی بسازید و محتوا را کپی/پیست کنید (روش گام ۲‑ب).

### گام ۲ — گذاشتن روی سرور

**الف) با File Manager سی‌پنل (ساده‌ترین):**

```
۱. cPanel → File Manager → public_html/wp-content/
۲. اگر پوشه‌ی mu-plugins نیست: + Folder → نام: mu-plugins
۳. وارد mu-plugins شوید → Upload → فایل را بکشید داخل
```

**ب) بدون دانلود (امن‌تر از نظر کدگذاری):**

```
۱. cPanel → File Manager → public_html/wp-content/mu-plugins/
۲. + File → نام: sa-content-guard.php → Create
۳. روی فایل راست‌کلیک → Edit → (اگر پرسید Encoding: utf-8) → Edit
۴. محتوای Raw گیت‌هاب را کامل کپی و اینجا پیست کنید → Save Changes
```

**ج) با FTP:** همان فایل را در `wp-content/mu-plugins/` بگذارید، حالت **Binary**.

> مسیر دقیق: `public_html/wp-content/mu-plugins/sa-content-guard.php`
> نه داخل `plugins`، نه داخل `themes`. پوشه‌ی `mu-plugins` کنار `plugins` است.

### گام ۳ — تأیید نصب

```
۱. پیشخوان → ابزارها → «سلامت محتوا» باید ظاهر شده باشد
۲. یک صفحه‌ی شهرستان را باز کنید:
   ← پایین مقاله بخش «پانویس‌ها و ارجاع‌های متن» آمده باشد
   ← لینک‌های ویکی‌پدیا از داخل متن رفته و فقط شماره‌ی بالانویس مانده باشد
۳. صفحه‌ی اصلی: استان‌های منتشرنشده کم‌رنگ و غیرقابل‌کلیک شده باشند
```

اگر صفحه سفید شد: فایل را حذف کنید، سایت فوراً برمی‌گردد. بعد بررسی کنید که
فایل با BOM ذخیره نشده باشد یا فضای خالی قبل از `<?php` نداشته باشد.

### اگر بعضی‌شان باز هم به پیش‌نویس برگشتند

وردپرس بعد از ویرایش گروهی، بالای صفحه می‌گوید دقیقاً چه چیزی کم است؛
ستون کنار هر استان هم نشان «n مورد ناقص» دارد. معمولاً یکی از این دوتاست:
تصویر شاخص ثبت نشده، یا ترم `province_tax` تنظیم نشده. هر دو با یک ویرایش
سریع درست می‌شود.

اگر عجله دارید، سه دریچه‌ی فرار به ترتیب نرمی:

```
۱. نمایش → سفارشی‌سازی → حالت دروازه = soft
   (این را افزونه هم رعایت می‌کند: هیچ‌چیز مانع انتشار نمی‌شود، فقط هشدار)

۲. در wp-config.php:  define( 'SA_GUARD_RELAX_GATE', false );
   ← برمی‌گردد به دروازه‌ی سخت قالب

۳. یک خط در mu-plugin دیگر:
   add_filter( 'sa_guard_blocking', '__return_empty_array' );
   ← همه‌چیز منتشر می‌شود، بدون استثنا
```

**برای برگرداندن همه‌چیز:** فایل را پاک کنید. هیچ چیزی در دیتابیس تغییر نکرده است.

## ماژول‌ها و خاموش‌کردنشان

در `wp-config.php`:

```php
define( 'SA_GUARD_DISABLE',      true );  // خاموشی کامل
define( 'SA_GUARD_CITATIONS',    false ); // پانویس‌سازی
define( 'SA_GUARD_SINGLE_H1',    false ); // تنزل H1 بدنه
define( 'SA_GUARD_DEAD_LINKS',   false ); // خنثی‌کردن لینک ۴۰۴
define( 'SA_GUARD_REMOTE_FONTS', false ); // حذف فونت گوگل
define( 'SA_GUARD_COMMUNITY_BOX',false ); // جداکردن بلوک پایانی
define( 'SA_GUARD_RELAX_GATE',   false ); // بازگشت به دروازه‌ی سخت قالب
define( 'SA_GUARD_HEALTH_PAGE',  false ); // صفحه‌ی گزارش
```

یا با فیلتر: `add_filter( 'sa_guard_modules', fn( $m ) => $m + array( 'citations' => false ) );`

## دو فایل XML

آن دو فایل روی گیت‌هاب نیستند — هیچ‌کدام از ۱۱ مخزن حساب `sarzaminaryan-arch` فایل
`*.xml` خروجی وردپرس ندارد و `Cc` هم فقط یک کامیت دارد. برای این ممیزی چیزی از دست
نرفت، چون `wp-content/plugins/sa-*-importer-*/data/*.json` دقیقاً همان HTML واردشده
به وردپرس است و سایت زنده هم بررسی شد. اگر باز هم خواستید بفرستید، پوش کنید و بگویید.
