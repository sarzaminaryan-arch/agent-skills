# چک‌لیست ویراستاری پیش از تحویل

هر خط یا تیک می‌خورد یا با دلیل کنار گذاشته می‌شود. بدون استثنا.

---

## الف) صحت

```
[ ] هر عدد، تاریخ، نام محصول و نسخه یا منبع دارد یا با [نیازمند منبع] علامت خورده
[ ] هیچ نقل‌قولی ساختگی نیست
[ ] لینک‌های خارجی باز می‌شوند و به همان چیزی اشاره می‌کنند که ادعا شده
[ ] دستورها/کدها واقعاً اجرا می‌شوند (یا صراحتاً «تست‌نشده» علامت خورده‌اند)
[ ] نسخه‌ی وردپرس/PHP/افزونه‌ای که مطلب بر اساسش نوشته شده ذکر شده
[ ] ادعای حقوقی، پزشکی یا مالی بدون هشدار نیست
```

## ب) ساختار

```
[ ] تیترها بدون خواندن متن، مسیر مقاله را نشان می‌دهند
[ ] هیچ تیتری تکراری یا هم‌معنای تیتر دیگر نیست
[ ] هیچ H2 با نام «مقدمه»/«نتیجه‌گیری»/«جمع‌بندی»
[ ] عمق تیتر از H3 جلوتر نرفته
[ ] نسبت فهرست به نثر زیر ۳۰٪
[ ] هیچ بخشی بدون دلیل از بخش دیگر خیلی طولانی‌تر نیست
[ ] جای تصاویر مشخص است (هر ۳۰۰–۵۰۰ کلمه)
```

## ج) زبان (اجرای خودکار + دستی)

```
[ ] humanize_lint.mjs با خروجی ۰ تمام می‌شود
[ ] هیچ عبارت ممنوع (ai-tells §1) باقی نمانده
[ ] انحراف معیار طول جمله ≥ ۶
[ ] خط تیره‌ی بلند کمتر از ۱ در هر ۵۰۰ کلمه
[ ] فهرست سه‌تایی حداکثر ۱ در هر ۵۰۰ کلمه
[ ] حداکثر ۲۰٪ بندها با رابط شروع می‌شوند
[ ] فارسی: ي/ك عربی صفر، نیم‌فاصله درست، گیومه «»
[ ] اصطلاحات فنی در کل مقاله یکدست‌اند
```

## د) صدا

```
[ ] حداقل یک موضع‌گیری صریح در مقاله هست
[ ] حداقل یک محدودیت/استثنا اعتراف شده
[ ] حداقل یک جزئیات خاص و غیرقابل‌حدس (عدد، پیام خطا، نام نسخه)
[ ] شروع با یکی از ۶ الگوی openings.md است
[ ] پایان یک قدم بعدی مشخص دارد، نه تعارف
```

## ه) دسترس‌پذیری و انتشار

```
[ ] متن جایگزین (alt) هر تصویر نوشته شده و توصیفی است، نه کلیدواژه‌انبار
[ ] متن لینک‌ها معنادار است، نه «اینجا کلیک کنید»
[ ] جدول‌ها سرستون دارند
[ ] هیچ اطلاعاتی فقط با رنگ منتقل نمی‌شود
[ ] چکیده (excerpt) بین ۱۴۰ تا ۱۶۰ نویسه است
[ ] اسلاگ لاتین، کوتاه، بدون ZWNJ و بدون stop-word
[ ] اگر سیاست انتشار الزام می‌کند، کمک هوش مصنوعی افشا شده
```

## و) تحویل به مراحل بعد

```
[ ] بریف تصویر شاخص نوشته و به featured-image-art-direction داده شد
[ ] متادیتا و اسکیما به wp-persian-seo داده شد
[ ] اگر خروجی بلوک وردپرس لازم است، به wp-patterns داده شد
[ ] فهرست claims بدون منبع به کاربر گزارش شد
```

## تست نهایی ۳۰ ثانیه‌ای

۱. اولین بند را بخوان. آیا می‌شود آن را سرِ همین مقاله یا هر مقاله‌ی دیگری گذاشت؟ اگر بله، بازنویسی کن.
۲. همه‌ی تیترها را پشت سر هم بخوان. آیا یک روایت می‌سازند؟
۳. یک بند تصادفی از وسط را بخوان. آیا چیزی یاد می‌گیری یا فقط کلمه است؟
۴. اگر خودت این را در جستجو پیدا می‌کردی، تا آخر می‌خواندی؟
